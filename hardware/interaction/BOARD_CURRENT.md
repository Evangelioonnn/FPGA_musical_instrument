## 已确定的硬件与产品方向

用户保留一块约478.917×95.504mm大板，不拆分。**本版不加踏板**；若实物可用，优先以它作为最终控制板，通过FPGA逻辑和交互配置扩展，避免时间不足再改版。踏板不作为后续音频功能的必要输入。

| 硬件 | 当前配置及用途 |
|---|---|
| 演奏键 | 25个透光MX类轴位，CPG151101S11热插拔轴座，轴座在背面；总两个八度，可分区移八度 |
| 功能键 | 11个，共36键构成6×6矩阵，每键独立二极管，阴极接ROW，列上拉；未选行应高阻 |
| 编码器 | 三个带按压模块接口，3.3V供电；每个A/B/按压三个数字信号 |
| 推子 | 五个独立电位器，主音量及四谐波编辑；不是五个数字推子模块 |
| 摇杆 | 双轴归中电位器，3.3V，两轴都已接ADC；弯音及第二表达参数可软件映射 |
| ADC | MCP3208，当前封装PDIP16，8通道12位SPI；VDD/VREF为3.3V |
| RGB | 25颗SK6812MINI-E-012候选实购物料，反贴；SN74AHCT1G125DBVR将3.3V数据升至5V，单路串行控制 |
| 状态灯 | 四颗普通LED，各有独立限流电阻和控制输出 |
| 固定 | 六个约3.2mm穿板安装孔，螺丝穿PCB后接铜柱；U4使用不超过6mm头径，避免大垫片侵入推子 |

本版所需信号IO为**30根**：矩阵12＋编码器9＋SPI4＋普通LED4＋RGB1，不包括电源和地。早期32根预算包含两个踏板输入，不能把尚未接出的踏板端子当作本版实物资源。30根可在原B的32根预算内安排，但准确整板FPGA分针和CST还未冻结。

普通机械键只有开关量，不具备逐键击键力度/压力测量。25个键不限制音色数量或音频复音槽数；后者仍取决于RTL、资源和时序。功能键、编码器按压及推子模式可以软件映射，但目前建议的具体菜单不是已实现固件。

2026-10-09用户决定：双触点时间差测速作为**独立力度表情小样**研究，不合并到已下单主板，也不要求小样带背光。可行性、公开实现和验证建议见[双触点研究](research/DUAL_CONTACT_VELOCITY_2026-10-09.md)；尚未选定具体器件或实现RTL。

## 真实接口针序

按连接器脚号识别；正面、背面和线缆插接面不能直接沿用同一个左右视觉顺序。

| 接口 | 脚号与网络 |
|---|---|
| RGB_PWR | **1=RGB_DATA，2=5V，3=GND**；覆盖旧讨论中的1=GND建议，当前丝印与实际网络一致 |
| 3.3V_PWR | **1=GND，2=3.3V** |
| ROW_D / COL_D | 1～6分别ROW1～ROW6 / COL1～COL6 |
| ADC_D / ADC_Z | 1=CLK、2=ADC DOUT（FPGA MISO）、3=ADC DIN（FPGA MOSI）、4=CS |
| TIM_F / RELEASE_F / EDIT_F | 1=GND、2=S1、3=S2、4=KEY、5=3.3V；接实际编码器模块前还需按其针序制作线束 |
| TIM_D / RELEASE_D / EDIT_D | 1=S1、2=S2、3=KEY |
| LED_Control | 1～4分别LED1～LED4控制信号 |

ADC CH0～CH4接五推子，CH5/CH6接摇杆两轴，CH7未用。MCP3208 CH7尚未接出可用模块，不能自动宣称已有备用插座。

RGB供电建议：RGB_PWR.2→底板J13.11（5V_Peripheral），RGB_PWR.3→J13.12（GND）。RGB_PWR.1→J13.13/A16仅为当前建议预留，须并入完整IO分配后再定CST。J13是双排针，这三针不在同一排连续位置。3.3V须另取底板确认的3.3V输出，不能从J13的5V替代；3.3V来源连接器及具体针号尚未最终指定。

NEO参考原理图中5V_Peripheral是共享约1A限流支路，不是RGB独享电流。上电先低亮度，结合整机负载测压降和电流；不以25颗全白满码保证供电。控制板两路电源共地，5V与3.3V分开。

## RGB装配与最终整改

- 25个灯窗全部**3.80×3.40mm、R0.50mm**；焊盘约1.70×0.80mm、左右中心距6.00mm，槽边铜距约0.245～0.255mm。LED7/11/12曾有独立局部封装漏更新，R3已全部补改。
- 实物发光面朝键帽、灯在PCB背面焊接，发光体穿过贯穿槽。不是把发光面朝PCB背后。
- 当前库旧脚号：**1=5V、2=DOUT、3=GND、4=DIN**；012实物手册：**1=GND、2=DIN、3=VDD、4=DOUT**。按功能与物理位置匹配，不能强行同号对同号。
- 实物GND切角脚落在PCB真正GND焊盘（当前库3号）。两组灯安装方向相差180°，不要全部朝一个方向焊，旧3D模型不作为唯一装配依据。详细顶面方向表见[R2](reviews/2026-10-08/RECHECK_R2.md)。
- 链首LED12、链尾LED31，末端DOUT空。完整链与关键尺寸见[R3最终复查](reviews/2026-10-08/RECHECK_R3.md)。
- C10已经移近U13，供电焊盘距VCC约2.54mm；U4孔中心距推子本体约3.39mm。未经新设计不要恢复旧位置。

## 制造建议与下一步

讨论过的建议参数：单片、1款、双面FR-4、1.6mm板厚、普通A级板材、外层1oz、绿油白字、过孔盖油、确认生产稿。用户最后展示的两个免费表面处理选项是无铅OSP/有铅喷锡，建议有铅喷锡便于手工焊接和返修；不是用户已提交的订单参数记录。

最终生产稿/制造预览核对25个贯穿灯窗、六个安装孔、轴座孔与推子孔；板厂如改槽或内角，重新核对装配。源文件改动后需更新指纹及审查结论。

板到后先做装配与供电检查，再逐项验证6×6防鬼键扫描、三编码器及按压、七路ADC、四普通LED、25颗RGB链，最后接音频及C的显示/蓝牙。当前音频V2仍为可回退基线，新控制板驱动与完整IO约束需要另建并验证。
