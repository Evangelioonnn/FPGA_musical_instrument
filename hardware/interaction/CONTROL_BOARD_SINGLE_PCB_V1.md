# 控制板单块PCB改版方案 · 2026-10-06

用户确认保留一块大板，不拆分；按现有控件补齐最终演奏、显示导航及脱机LED引导所需硬件。本文是可据以修改原理图的方案，不代表新增线路已画入EDA或已经板测。

**同日更新：用户选择透光键帽、透光MX类轴体及CPG151101S11热插拔轴座；灯区改为25颗可寻址RGB，准确选型/针号/供电/开窗边界见[RGB接线方案](RGB_BACKLIGHT_V1.md)。旧TLC59282单色方案停止采用。**

角色：A/B控制硬件协作。文档分支 `codex/keyboard-pcb-review-20261005`，起点 `e70e4db`；本轮只新增方案及核对器件资料，没有修改KEYBOARD.eprj、RTL/CST、投板或push。现有拓扑来自2026-10-05只读审查；用户后来报告已去掉安装孔周围无用铜焊盘、增加4.7uF入口电容并通过原生DRC，此为用户反馈，未重新审查其更新后的完整制造文件。

## 1. 本轮范围

- 保留25演奏键、11功能键的6×6二极管矩阵；保留3只带独立按压编码器、5推子、摇杆及MCP3208。
- 增加25颗SK6812MINI-E-012 RGB和SN74AHCT1G125DBVR电平缓冲；原4颗3.3V状态灯保留直接GPIO和限流电阻。
- 接通摇杆第二轴到CH6；CH7引出备用接口。
- 预留两个无源开关踏板接口和输入电路，可暂不装连接器/不接踏板。
- 整理供电、信号连接器、测试点及键灯编号。无需再增加演奏键、旋钮、ADC、MCU或USB通信。
- 现有开关式琴键不具有真实击键力度采样；本方案不新增逐键压感。32复音不等于需要32实体键。

现有6×6矩阵仍每键串二极管、阴极朝ROW，COL各10k上拉；扫描选中行拉低，其余高阻。新灯与行列网完全独立。

## 3. RGB器件与连接（替换原单色驱动方案）

按[RGB_BACKLIGHT_V1.md](RGB_BACKLIGHT_V1.md)实施。25颗SK6812MINI-E-012，5V供电，AHCT将单根FPGA数据转换为5V电平；原4颗状态灯保留。**不再安装TLC59282，不迁移原4颗状态灯到RGB链。**

当前灯珠商品C5149201链接的新版资料中，针号为1=GND、2=DIN、3=VDD、4=DOUT；旧版SK6812MINI-E为1=VDD、2=DOUT、3=GND、4=DIN。物理引脚功能/观察面、符号及封装必须同时核对，不能把旧库针号照抄进新表。规格书另对三色同时点亮要求不超过70%灰阶，不能默认全白满码为正常工况。

RGB区独立5V电源入口，设计供电能力按5V/2A准备；已核对NEO Rev1.4的J13第11/12针5V/GND来自1A限流的共享5V_Peripheral支路；低亮度引导可优先使用，需扣除其他外设及验证瞬态，不能视作独享2A。控制板原3.3V电路保持，5V与3.3V共地但不相连。灯位与轴座/实际轴体尚未完成机械叠图，原理图可以先画，开窗位置不能仅凭透光键帽认定已匹配。

## 4. ADC及连续轴

MCP3208 PDIP-16：CH0～CH7依次为1～8脚；9=DGND、10=CS/SHDN、11=DIN、12=DOUT、13=CLK、14=AGND、15=VREF、16=VDD。继续3.3V VDD/VREF，地共地；SPI映射保持原方案。

- 既有CH0～CH5保留。
- 摇杆第二轴电位器两端接3.3V/GND，中间抽头经1k到CH6（MCP3208第7脚），CH6侧100nF到GND；复用原轴相同电路。摇杆实际端子编号须按该元件资料/符号核对，不能仅凭物理位置猜。
- 备用模拟接口J_AUX：1=3.3V、2=AIN7、3=GND。AIN7经1k到CH7（第8脚），CH7侧100nF到GND。AIN7留100k下拉位置，默认装入作为未连接时默认零；高源阻传感器接入时重评负载并可不装。
- AIN7输入范围0～3.3V；不是可直接接5V传感器或未知有源踏板的通用端口。
- 保留原入口4.7uF和ADC现有100nF；VREF附近另预留/放置100nF。模拟输入滤波电容尽量靠ADC侧。

## 5. 两路踏板预留

每路使用两针防反插连接器，1=PEDAL_CONTACT，2=GND；只连接无源开关。可由线束转到外壳上的踏板插座，无须现在确定PCB安装的大型插座。

每路：

```text
3.3V ──10k──┬── PEDAL_IN（到FPGA）
            ├──100nF──GND
            └──1k──接口1脚──无源踏板开关──接口2脚/GND
```

开路为高，闭合约0.3V，为低有效。两路网络独立；软件支持常开/常闭标定。不要把两个输入并在同一矩阵线上。

长外接踏板线的静电防护应在连接器旁留可装保护器件的位置，具体器件在外部插座/线束确定后核对；该RC不等于完整ESD保护。未接踏板时仍可使用面板按钮，所有功能不依赖立刻采购踏板。

## 6. IO、电源与布局

| 功能 | GPIO |
|---|---:|
| 6×6矩阵 | 12 |
| 3编码器A/B/按压 | 9 |
| MCP3208 SPI | 4 |
| 原4颗状态LED | 4 |
| RGB串行数据 | 1 |
| 两路踏板 | 2 |
| 合计（不含电源/地） | 32 |

原4颗状态灯保持直接GPIO，已在上表计数；RGB单独占1根。J13有36直接候选GPIO，可满足数量预算；准确底板针号/FPGA球号仍由统一线束/CST表冻结。J13第11针为5V，第12针为GND，没有专用3.3V电源针。C蓝牙继续保留PMOD额度。

ADC、推子、摇杆、编码器和原4状态灯继续3.3V；25颗RGB及AHCT缓冲使用独立5V_LED网。两路共地，不并联电源。RGB供电按新方案5V/2A入口规划；不能把RGB电流加到3.3V PMOD线上。底板J13外设5V已查到1A共享限流，可作为低亮度引导的首选供电路径；支路余量及PWM瞬态仍需测量，新增RGB未板测。

- 主电源入口统一1=3.3V、2=GND并明确丝印；原同一两针全为电源/全为地的接口若保留，明确标出3V3/3V3、GND/GND，不能与新接口混用。
- 原矩阵/编码器/ADC信号组可以保留，增加清晰针1、信号名及伴随GND；不必为“一根线”改架构。
- 保持双面GND连通及连续回流；驱动电流回路与ADC参考/模拟线分开布置，不在ADC下切割地平面。
- 预留电源、ADC SPI、灯总线、代表性ROW/COL测试点和可夹探头的GND。
- 固定物理键灯号K00/L00～K24/L24；丝印可同时标琴键名称，但逻辑键号不随八度变化。现有元件SW编号不是演奏顺序，不按SW序号盲目分配灯。
- 保留用户已经改好的安装孔及4.7uF；改版后重新铺铜、DRC、检查新增器件封装和制造输出。旧DRC通过不覆盖新线路。

## 7. 实施顺序及整合

1. 按RGB_BACKLIGHT_V1新增25颗RGB、AHCT缓冲和5V电源/去耦/数据电阻；保留原4灯。
2. 接摇杆第二轴、CH7备用口；画两路踏板预留电路。
3. 给11功能键及25琴键确定物理标签，生成矩阵ROW/COL、物理key_id、LED通道对照表。
4. 整理接口及电源入口；新线路同步到PCB，校验灯在键帽与手指遮挡下的可见性。
5. 原生DRC和制造输出核验后再投板；上板先电源/输入/全灯测试，再结合音频和C引导。

软件：A/B逐项约定6×6扫描、ADC、编码器/踏板输入及LED总线RTL作者；C产生逻辑灯帧和UI事件。只有一套物理LED总线驱动。音频事件不能等待LED/视频刷新。现有固件尚不能直接完整驱动新增硬件，需适配并重跑整机PnR和板测。离线曲谱可由FPGA ROM/RAM承载，不为本轮控制PCB强加MCU/曲谱存储芯片；下载曲谱掉电保存、长PCM录音不是本方案已解决的能力。
