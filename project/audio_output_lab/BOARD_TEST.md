# 本轮怎么听

四份都用现有矩阵、旋钮、板载键，无需重新接线。全都默认钢琴、音量18；上一轮默认24。先把外部音箱/耳机调到舒适音量。

## 建议顺序

1. **00对照**：启动后按矩阵S1(do)不松，再按S2(re)，再加S3(mi)，然后一起松开。先18档，再逐格到19、20、21，最后按需要到24。记录新增粗糙声和颤动在哪一档出现；按S9/S10/S11重复一次高八度。S1/S2/S3同一矩阵行，不会构成矩形鬼键。
2. **02错开边沿**：保持外部音箱音量不变，重复00完全相同的档位和音符。重点是尖锐分量、额外粗糙声、起音是否有改变。02的数字声音逐样本应与00相同。
3. **03整体反相**：同样重复。如果有明显变化，告诉我“哪些音/哪些音量/单音还是复音”；整体反相本来不应改变频谱幅度，但真实系统或听感可能有不对称，这只是一条线索。
4. **01钢琴余量**：此版钢琴明显更轻，开机音量18；可往增大方向转6格到24上限。钢琴最大约相当于00的18档，拨弦仍是原来的音量。先试听能否稳定演奏，再用有源音箱适当补偿响度比较，防止仅因变小声而听不见问题。补偿后切拨弦前先调低外部音量，因为拨弦没有被额外衰减。

从任意音量找绝对档位：确认处于音量模式，向减小方向转至少24格到静音，再往上数。若此前从最小非零档开始计数，旧反馈格数会差1；本轮以静音0为基准。每格原表仍为3dB，24封顶，不会循环。

板载S1按一次切换钢琴/柔和拨弦；板载S2普通延音；板载S4短按切模式，长按止音。切音色只影响新音，旧音自然收尾。双区、释放功能同上一轮，本轮重点不必重复全部验收。

## 必须区分的结果

| 观察 | 能支持的判断 | 不能直接得出的结论 |
|---|---|---|
| 01更小声且更干净 | 降低钢琴电平可改善可闻异常 | 不能证明溢出/DAC损坏，也不代表同响度彻底修复 |
| 02在同档位明显改善 | 发送边沿/板级耦合更值得调查；新发送器有采用价值 | 仿真不能测板上振铃，也不能仅凭听感定具体器件 |
| 03在同档位明显变化 | 对码值/极性敏感的非理想行为值得调查 | 不证明一定是模拟或一定是RTL |
| 00/02/03一样，01只有更轻 | 本轮未找到保持响度的修复 | 不代表所有软件路径已排除 |

八同音/八不同音由数字仿真验证容量和峰值；无二极管矩阵不能任意按八键验收，否则鬼键保护会静音。18档只有此前三音主观依据，不保证任何和弦都无噪声。

请按如下简表反馈即可：

```text
00：低音双音/三音出现新增声的档位；高八度是否不同
02：相对00，尖锐声/粗糙声/起音变化
03：相对00变化
01：24档能否接受；有源音箱补偿后改善是否保留
拨弦：本轮有没有退步
```

如需电脑对照：`evidence/audio/output_control_volume18.wav`、`output_control_volume24.wav`、`output_headroom_volume24.wav`、`output_polarity_volume24.wav`。前约0.9秒是C3→C3+D3→C3+D3+E3→释放；之后高八度、八同音、八不同音、钢琴与拨弦混合及释放。是实际RTL样本，没有响度归一化。02用00的参考即可。

首轮板测已反馈：02/03相对00无明显差异；01上限小很多；整体起音问题未再听到，颤动及伴随杂音改善但未消失，勉强可接受。是否在24档等电平比较尚未确认，详见[板测记录](../../evidence/audio_output_lab_2026-09-27/BOARD_LISTENING.md)。以上步骤保留作后续对照参考，不代表用户已逐项执行。
