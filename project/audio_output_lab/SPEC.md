# 输出链路与电平隔离实验 · 2026-09-27

角色A；分支 `codex/audio-output-isolation`；起点 `db653ef`。允许目录：本实验、相关项目状态/索引/证据。旧palette/final源码不改，未授权远端发布。本轮目标是提供有区分力的可演奏候选，音质是否修复由用户板测决定。

## 固定条件

八声部、50MHz、Fs=50MHz/1040；矩阵、EC11、三个板载键、电气约束沿用palette。默认01 precision钢琴，切换为06 warm拨弦；两者的谐波钢琴算法相同。保留双区/移调/音量/释放/普通延音/长按止音。拨弦不强行延音。没有按活跃声部数归一化、自动压缩或偷音。

## 四个独立工程

| 名称 | 唯一主要变量 | 用途 |
|---|---|---|
| 00_control | 01钢琴＋06拨弦，旧发送器 | 统一对照，默认钢琴；与旧06同控制参数时样本应相同 |
| 01_piano_headroom | 每个钢琴声部幅度固定1/8，拨弦不变 | 高音量新增异常的缓解候选，不宣称根因修复 |
| 02_edge_spacing | DIN比BCK下降沿晚40ns，WS晚80ns | 保持PCM/采样率/BCK不变，检查同时翻转相关性 |
| 03_polarity | 最终左右PCM同时反号；-32768饱和为32767 | 同响度诊断；明显差异支持调查与码值/极性相关的非理想行为，不直接证明DAC坏 |

01在谐波乘积转Q4时完成固定缩放及对称舍入，保留原来的声部包络、调度和尾音；不能在切换音色时缩放整条混音，否则会改变仍在发声的旧音。最大钢琴音量约等于旧旋钮18格（从静音0计），这只依据用户三音观察，不是八复音安全保证。其它工程音量表不改。启动音量统一设18，便于安全比较；旧版默认24，验收必须按绝对档位对齐。

02为50MHz同域寄存器延迟，无新时钟/PLL。每半位13周期=260ns，DIN到下一BCK上升沿仍有220ns，WS有180ns；不改变上升沿采样位序。PT8211 V1.6第4页图1/2为右对齐、上升沿采样，WS低右高左；第5页未给独立setup/hold数值，不把内部RTL间隔当成板上已测裕量。不重复之前16/20位和过采样实验，也不擅自改驱动电流或电压。

## 验收

数字：原/新未缩放银行逐样本相同；钢琴缩放独立数学检查，拨弦逐样本不变；C3/D3/E3、C4/D4/E4、八同音最坏叠加、八不同音、松键/延音/混合音色；音量18–24；clip/deadline/未知值监测。实际BCK上升沿独立解码两种发送器，覆盖全16位输入及左右独立数据，极性端点检查。真实1040周期与渲染省略空闲周期分别比较。

实现：四份独立gprj/fs、来源哈希、PnR/50MHz时序及A+输入预算(29000 Logic/17000 Register/70 BSRAM/78 DSP/19 IO)检查。板测：用户反馈前全部pending。无新增音色、效果器或更高复音，无板卡写入。
