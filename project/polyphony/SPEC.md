# M2：四声部管理与混音规格

2026-09-18：用户明天去实验室定位音质问题，当前推进可独立验证的四复音数字核心。模拟音质未验收，不以本阶段仿真替代原问题结论。既有 instrument/audio_quality/audio_format 源码和比特流保留。

## 边界与接口

- 50MHz单时钟，`sample_ce`是使能，沿用Fs=50MHz/1040。所有控制输入须已经同步到clk，真实矩阵/编码器/ADC适配尚未实现。
- `event_valid && event_ready`在时钟上升沿接受一条事件；`event_on=1`按下，0松开，`event_note[6:0]`为0..127 MIDI音符。可连续每周期一条；valid持续为1表示连续事件，上游须按握手更新。
- `all_notes_off=1`优先释放所有已占用声部，期间ready=0，事件应由上游保持。同步高有效rst清除所有状态。没有排队FIFO，外部异步输入不能直接接此接口。
- 每声部独立DDS相位、频率及ADSR；复用原 `synth_voice`/正弦表/包络。on/off由管理器产生，接受事件后下一周期作用于声部，事件与sample_ce相遇的行为继承M1规格。
- 本版无力度、延音踏板或动态音色；同一音符只有一个逻辑持键状态，重复note_on视为重触发，不能表达多个来源叠按同一个音符。

## 分配和释放的确定规则

依次选择：

1. 已占用同音符：重触发原声部，不另占一路；释放尾音中同音符也重触发原声部。
2. 空闲声部：选编号最小者。松键且包络IDLE即为空闲。
3. 没有空闲：优先抢占已松键、仍在RELEASE尾音中的声部；其中选最近一次note_on最早者。
4. 四路都持键：抢占最近一次note_on最早者。

用4个唯一的0..3顺序等级维护相对先后，避免长期演奏的时间戳回绕问题。重触发更新为最新；释放不改变触发先后。note_off只作用于匹配音符，已被抢占的旧音符off不得释放新音符；重复off和未知off忽略并输出`event_ignored`诊断脉冲。

`occupied`包含持键和未结束的尾音；`held`仅表示持键。on/off脉冲、音符总线和标志明确按声部0..3排列（voice0在最低位）。`voice_stolen`仅在抢占其他尚占用音符时输出一周期，不把同音符重触发算抢占。已有声部相位/包络不会因分配其他声部重置。

重触发和抢占沿用M1的相位/包络连续策略，不强行清零；抢占时频率改变仍可能产生瞬态，不宣称完成无点击抢占设计。抢占后的旧音符不会自动恢复，须再次按下才分配。

## 混音

- 四个signed16样本分别符号扩展到signed18再相加；全范围为-131072..131068。
- `mixer4`固定算术右移`OUTPUT_SHIFT`（默认2，即总和除4向负无穷取整），然后饱和到signed16[-32768,32767]，正负溢出不得回绕。`clipped`与有效输出同周期。
- 固定增益不随当前发声数量改变，避免松开一个键导致其他音符突然变响。四路原低幅声部相加后默认仍限制在-512..511；这是保守验证增益，最终DAC/模拟增益设计尚未完成。
- 声部E3输出有效，混音器下一周期E4输出有效；sample_ce至少间隔5个周期，实际1040。混音样本保持到下次有效更新，valid为一周期脉冲。PT8211下帧锁存，因此本版继续复用原串行输出。

## 演示与验证

电脑仿真和可构建顶层使用8个一秒槽：静音 → C4 → 加E4 → 加G4 → 加C5（四音）→ 松E4（三音）→ 依次松C4/G4/C5 → 静音。第6槽在采样0/64/128处依次松三个音，其余按下/松开在槽首。总8秒循环，频率/ADSR均实时计算，无录音回放。

必须验证：

1. 管理器：空闲优先、四音独立、第五音抢占、尾音优先、同音重触发、旧off、完成释放、panic、复位、连续事件。用独立队列/字典软件模型生成确定性随机序列，避免只复制等级算法。
2. 混音器：零、极值、正/负溢出、相抵、失效保持，OUTPUT_SHIFT=0和2对照独立整数参考。
3. 核心：真实采样计数导出四路及总和；检查E4有效、分音频率、四音共存、单独松E4不影响其他三声部、全部松开后归零。
4. 串行集成：真实50MHz、缩短演示计数、独立引脚接收器，检查双声道帧等于预期混音样本，无撕裂或符号错误。
5. Gowin综合/PnR、资源/内部时序和引脚复核。未实测不能标记已完成四复音板卡/按键验收；自动演示的资源可能优化未用音符分支，不能等同完整输入方案最终占用。
