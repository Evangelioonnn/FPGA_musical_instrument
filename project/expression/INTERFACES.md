# 给交互模块和通信/显示模块的接入说明

本文件描述M3候选核心实际端口。引脚和外部串口/BLE协议未定义；它们由后续适配层转换成本接口。所有输入同步到50MHz，异步传感器/串口先同步或跨域，矩阵去抖不在合成核心内完成。

## 给交互模块负责人

一次音符操作占一个系统时钟，只有`event_valid && event_ready`时算接受。ready为0则保持整条事件，不能仅保持valid却更换数据。持续valid每周期产生一条事件，不能拿它直接表示持续按键。

| 字段 | 位数 | 含义 |
|---|---:|---|
| event_kind | 2 | 0按下、1松开、2重定音、3保留 |
| event_note | 7 | 0..127音符身份，A4=69；采用编号不等于已经实现MIDI电气协议 |
| event_value | 7 | kind=2时的目标音高，其余忽略 |
| event_velocity | 9 | kind=0时的线性幅度0..256，>256钳位；0转为松开 |

例：按下60 → 重定音(身份60、目标67) → 松开60。重定音期间ADSR/相位不重置，也不增加声部。和弦每个音各发一条事件；8条连续事件仅160ns，真实输入扫描/去抖通常才是主要延迟来源。

物理键映射仍由上游负责。两个物理键映射同音时要明确聚合计数；持键时变八度，松开必须送原按下身份；从串行接口输入时必须定义断线和队列溢出处理，不能丢弃松键。当前核心没有这些输入源管理功能。

## 给通信/参数负责人

`cfg_valid && cfg_ready`接受一条`cfg_addr[3:0],cfg_data[31:0]`写入。下一周期可见ack；accepted指示是否合法，applied返回采用值，拒绝时返回0xffffffff。应答不是完整读寄存器协议，不能把它当成已实现UART/BLE命令解析。

地址表见SPEC.md。控制器可以将ADC/旋钮值映射到0号音量、1号音色、2号弯音、3号滑音速度、4/5号踏板、7..10号包络；映射曲线、死区和校准由输入/控制层负责。支持本地/蓝牙两来源前还需增加仲裁、协议版本和状态读回。

- 音量：0..65536代表线性幅度0..1，512个采样内走完整个范围。软音可用较低目标增益验证，但没有独立软音踏板状态机。
- 音色：0纯正弦，1增加第三谐波，2增加第二/第三谐波。切换约10.65ms完成，不改变按键布局或声部身份。
- 弯音：`round(65536*2^(semitones/12))`，范围±12半音；例如+2半音约73562。默认glide=0立即更新频率，想平滑弯音可设置非零glide_delta。
- 滑音：delta单位为每采样允许变化的相位增量码，不是毫秒。两频率f0/f1的近似滑音时间为`ceil(abs(step1-step0)/delta)/Fs`。示例delta=2048，A4→E5约0.199秒。
- 踏板：sustain保持所有已起音、仍有gate的松键音；sostenuto只锁存踏板上升沿之前的held。两个都为0后，仅真正松开的音进入release。
- 全释放：6号写1，所有声部走release，不是立刻截断样本；复位才直接清零。不把cfg_valid长高当一次命令。
- ADSR：A/D/R是每采样步长，S是保持电平；完整攻击近似65535/A/Fs秒，默认释放从32768需ceil(32768/R)/Fs秒。参数在note_on时快照，持续音不随默认S变更突然跳变。

需要“先换音色/包络再按下”时，等待配置应答后再发音符，避免跨层寄存器时序产生歧义。多个参数要作为一个预置原子切换时，尚需增加预置缓冲/提交操作，当前不是原子多寄存器事务。

## 给显示负责人

`occupied`包括尾音；`held`只表示手仍按着；`gated`包括踏板保持；`sost_latched`是选择性延音捕获集合。声部编号只是分配槽，不是固定键号。

`notes/pitches`每声部7位，`voice_samples/envelopes`每声部16位，`steps`每声部32位；声部0在最低位。N默认8，可选4，显示不要写死4路。gain/weight2/weight3可显示实际平滑参数，而非仅显示目标值。

`meter_valid`每1024个有效输出样本出现一次，约46.95Hz，伴随窗口peak、最后样本和clip_seen。峰值为无符号16位，-32768绝对值是32768；状态无反压，慢屏幕可以读取最新快照。若做波形，需按屏幕采样策略另建窗口/缓存；最后一个样本不等于整段波形。当前顶层只接耳机，未增加屏幕或LED引脚，综合可能移除无消费者的meter逻辑。

## 延迟与已知边界

sample_ce到合成输出valid为9个系统周期（180ns）；PT8211在后续帧装载并串行输出。这个值仅描述数字内部管线，不能替代外设扫描/去抖/传输、DAC和模拟链路的总延迟测量。sample_ce实际间隔1040周期，本核心最低允许16周期。

该工程支持8个独立声部。每声部的三个谐波由同一相位按整数倍派生，不把24次波表读取宣传成24个独立声部。音色为数学合成配方，暂无真实乐器建模。无点击抢占、键盘单音连奏策略、逐键压力、滤波/混响、无线与显示硬件均另行开发。
