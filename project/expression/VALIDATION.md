## 音频证据

实际采样率50MHz/1040=48076.9230769Hz，WAV整数采样率48077Hz。初末静音通过，原始输出范围-166..177。`audio/*listen.wav`及六个分段使用统一32倍电脑试听增益，原始WAV保留原码值；增益没有进入FPGA。

| 情况 | 期望基频/二次/三次谐波峰值（输出码） |
|---|---|
| 单A4纯正弦 | 32 / 0 / 0 |
| 单A4音色1 | 24 / 0 / 8 |
| 单A4音色2 | 16 / 8 / 8 |
| 音色2四分之一音量 | 4 / 2 / 2 |

最小二乘频率分量拟合验证上述幅度，每项误差小于0.6码。力度64/128/256分别约8/16/32码。滑音A4→E5→A4每采样变化不超过2048步长码且精确到达目标；弯音+2半音的目标比例73562/65536。普通踏板松键后仍有C4/E4/G4三基频，抬起后归零；选择性踏板只保留C5，之后弹的E5松开可归零。八声部段对每路输出分别拟合其三个谐波，确认独立频率与同时占用。

音色切换与音量变化有明确参数限速，相位在声部测试中逐采样检查；不据此宣称所有抢占、极端音高和控制组合都无可闻瞬态。详细实测数值在`sim/audio_analysis.json`。

## 时序修正与资源优化

第一次综合能够生成比特流，但8声部串行比较链造成最差setup -0.265ns、53个违例端点。该版本不作为交付的可下载候选。之后将抢占选择改为并行比较，并把音色运算等价改写为：

```text
原式：s1*(65536-w2-w3) + s2*w2 + s3*w3
现式：s1*65536 + (s2-s1)*w2 + (s3-s1)*w3
```

中间位宽保留，最后统一截位，减少重复乘法。**优化前后完整样本文件及原始WAV的SHA256均相同**；管理器/全部功能回归通过。参考源码、报告和指纹在`reports/before_optimization`，最终摘要在`reports/build_summary.json`。

| 指标 | 优化前 | 最终版本 |
|---|---:|---:|
| Logic | 7306 | 7271（5054 LUT + 2217 ALU） |
| 寄存器 | 1388 | 1516（1514逻辑FF + 2IO FF） |
| BSRAM | 24 | 24 |
| DSP等效单元 | 58.5 | 49 |
| Fmax | 49.345MHz | 61.405MHz |
| 最差setup slack | -0.265ns | +3.715ns |
| Setup TNS / 违例端点 | -6.907ns / 53 | 0 / 0 |
| 最差hold slack | 见参考报告 | +0.051ns |
| Hold TNS / 违例端点 | 0 / 0 | 0 / 0 |

最终占用约12.14% Logic、20.34% BSRAM、41.53% DSP（工具向上显示13%/21%/42%）。DSP由8个MULT27X36和33个MULTALU27X18组成，不能把原语实例个数直接当DSP等效占用。当前8声部不能不加评估就机械翻倍到16/32，后续可比较共享波表端口、乘法器时分复用、音色算法与效果器预算。

每个声部的三个谐波共享基础相位并按整数倍派生，所以本工程按8个独立声部描述，不将24个ROM读取算作24复音。

## 使用边界

此报告的资源对应自动演示顶层，未使用参数路径/状态可能被优化，不等于所有真实输入、蓝牙、屏幕和效果器加入后的最终占用。资源未用完不代表剩余封装IO都能从底板安全使用，新增引脚需另行核对。

核心sample_ce→输出valid为9时钟，即180ns；串行帧、外设扫描/去抖/传输和DAC/模拟延迟仍需整链测量，不直接宣布≤10ms整机指标已验收。

本版没有混响/延迟效果器、自动单音连奏优先级、逐键压力、物理扫描器、蓝牙与显示硬件。软音可以通过较低总增益实验，但没有专门的软音踏板状态机；三种音色也不是三种真实乐器建模。真实音质、高音跨谐波保护边界与抢占瞬态待听感/仪器验证。

原instrument、audio_quality、audio_format和polyphony清单中共94个记录项已复核未变，包括源码、约束与原bitstream；诊断链路可继续复现。
