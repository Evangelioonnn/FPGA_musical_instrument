# expression 首轮板测与声音问题复核

日期：2026-09-18。依据：用户实际板上听感、当前 expression_demo/voice/mixer 源码和已有 RTL 样本。没有模拟录音、实际引脚采样或示波器测量。本轮没有更改 RTL、音频文件或比特流。

## 用户反馈与验收边界

| 项目 | 用户反馈 | 当前结论 |
|---|---|---|
| 普通延音 | 底噪大 | 音质问题保留；不能直接认定延音状态机产生噪声 |
| 选择性延音 | 后面有尖突、瞬间抖动声音；追问位置后回答“选项1，2吧”，即约16秒第二音和约17秒最终释放处 | 两个时间点分别排查，位置尚不精确；不能把二者都归因于短音 |
| 三种谐波配方 | 最开始一个音色，后面杂糅，不像三种分别的音色；最终音色另选 | 只保留为合成/切换机制实验，不将本演示三配方确定为产品音色库 |
| 力度 | 逐渐增强合理，可用于确定好的音色 | 相对力度变化获主观认可；真实击键/压力传感还未实现 |
| 音量/静音 | 中间暂停正确 | 静音现象获主观确认；不推断模拟底噪归零 |
| 滑音/弯音/释放 | 勉强可以，按交互需求再决定是否使用 | 实现保留为可选表达能力；未锁定手势或产品默认模式 |
| 八音和弦 | 听感还可以，像钢琴多个键同时按，无法分辨是哪八音 | 整体听感认可；不由听感单独证明八声部独立性或全部端到端指标 |
| 原尖锐声 | 本次没有听到；新旧音色也不同 | 记录为“本次条件下未复现”，不能称为已找到原因或修复 |

保留此前 instrument 纯正弦+ADSR 的原始音色。用户描述“像钢琴”是听感偏好，不将数学正弦或三谐波模型改记为真实钢琴建模。

## 已确认的演示问题：第二个音过短

expression_demo 在第16秒让 E5 起音，在该秒第130个采样松开。Fs=50 MHz/1040，因此持键仅 **2.704 ms**。已有仿真中第二声部最后一个非零样本位于该秒第3076个采样，即起音后约 **63.981 ms**；尾音也很短。

这是对“后按音不被选择性延音捕获”的逻辑验证，但持键长度不适合主观演示，可能听起来像短啾声/突音。它能解释第16秒附近的一个候选声音，**尚不能确认就是用户所述异常，更不能解释第17秒的释放处**。

第17秒释放 C5 后，现有数字样本该秒后半段全为0，整秒最大相邻样本差为3码（未加电脑试听增益）。这只说明此次 RTL 参考没有大幅数值跳变，不能排除较小量化声、模拟瞬态、硬件样本异常或用户所指时刻不同。数值结果见 `first_board_analysis.json`。

下一版演示建议：E5持键延长到0.4～0.5秒，松开后给足独立尾音时间，再隔开一段释放C5；分别标注第二音松开与踏板释放，避免接到力度段时混淆。改完需重新仿真/构建，目前仍是原130采样版本。

## 原尖锐声未复现：对照条件不同

- 新旧串行输出都复用 instrument 的 PT8211 驱动和相同音频引脚；没有证据表明本次换了 DAC 协议就修好了。
- 新工程8声部固定除以8，在相同纯正弦、最大力度、默认包络保持段及总音量下，单音名义峰值约32码；原单声部约256码，数字幅度差 **18.06 dB**。这不是实测声压差，也不代表DAC低电平性能一定更好。
- 新演示的音高、和弦、谐波和包络触发安排也不同。附加谐波与和弦可能改变异常的可闻性；输出工作点、数值路径和综合实现也存在差异，暂不能选择其中一项作为原因。
- 普通延音只改变何时释放，不应额外创建噪声源；需要比较同一组音在“持续持键”和“松键后由踏板保持”时的实际输出，再区分量化/模拟噪声、拍频或控制异常。

有针对性的后续对照：原单声部原电平、原单声部降低18.06 dB、新引擎同纯正弦/同音高/同低电平，统一持键与包络时长，并在同一次实验中保持供电/耳机/接线相同。该对照尚未生成新固件，不把本轮不同演示当成控制变量实验。

## 八音与音色解释

本演示八音为 C3/E3/G3/C4/E4/G4/C5/E5（MIDI 48/52/55/60/64/67/72/76；C4=60）。它们由跨八度的C大三和弦组成，只有C/E/G三个音级，有较强融合感；不能要求用户靠耳朵数出八条声部。若要主观展示独立性，可后续逐个加音、逐个减音，配合状态指示；已有数字声部/频谱验证继续保留。

开头不是三次分别起音，而是同一个 A4 持续发声时修改谐波权重，三个配方都来自同一正弦家族。因此“像一个音色逐渐变杂”的反馈与演示方式一致。后续选音色应用同一短旋律分别演示纯正弦、电钢琴/钟铃、拨弦等候选，每款同时比较起音、保持、松键和力度；不只比较静态谐波比例。

## 下一步优先级

1. 把两个疑似突音时刻分开，制作更清晰的选择性延音短测试，避免新增音色干扰诊断。
2. 以同音、同幅度、同包络对照旧尖锐声；实验室可用时再测真实数字与模拟波形。
3. 接入板载按键/到货输入的控制事件。音量、力度、声部与踏板管理可复用；对音色、滑音/弯音的最终产品选择仍保持开放。

竞赛所需实时变调能力继续保留；用户暂不决定采用滑音/弯音交互，不意味着删除实时变调能力。
