# M3 表达控制与八声部候选工程

本工程为2026-09-18夜间开发批次，复用原PT8211输出、音符表、数学正弦ROM和ADSR内核。既有音频诊断与四复音工程保持原样。**首轮板测已获得音量静音、力度与和弦的主观认可；延音噪声/突音待定位，原尖锐声仅在本次条件下未复现。** 详情见 `reviews/FIRST_BOARD_REVIEW.md`。三种谐波配方不作为最终产品音色，原纯正弦保留。数字验证和资源/时序结论见VALIDATION.md。

## 功能

- 可配置4/8声部，独立相位、包络和确定性抢占。
- 三种谐波配方音色，持音时平滑切换。
- 总音量平滑与精确静音，每音符独立力度。
- 普通延音、选择性延音、全释放。
- 保持原音符身份的实时重定音，线性频率滑音，全局弯音比例。
- 新音符快照ADSR参数，已有音符保持自身包络设定。
- 参数写入应答，声部状态、音量峰值和削波快照，供后续输入/蓝牙/显示适配。

各功能边界见SPEC.md，队友接入示例见INTERFACES.md。输入布局、传感器与新引脚未在本工程中锁定。

## 早晨先在电脑试听

音频由RTL仿真逐样本导出，不是板卡录音。`audio/00_full_demo_listen.wav`与分段文件统一放大32倍，便于电脑听；原始数字输出另存`00_full_demo_raw.wav`。没有将这项试听增益加入FPGA，比特流仍保留低监测幅度。

| 文件 | 内容与关注点 |
|---|---|
| 01_timbres.wav | 同一个A4保持发声，纯正弦→第三谐波配方→第二/第三谐波配方；听音色变化，音高不变 |
| 02_volume.wav | 同一音色全音量→四分之一幅度→静音→恢复；听平滑衔接 |
| 03_glide_bend.wav | 持音A4→滑到E5→滑回A4→整体升两半音→释放；持续段没有重新起音 |
| 04_pedals.wav | 普通延音保持三音和弦；选择性延音捕获C5，随后新弹E5松开可结束，C5继续直到抬踏板 |
| 05_velocity.wav | 同音三次，力度64、128、256，幅度比例约1:2:4 |
| 06_eight_voices.wav | 八个不同音同时存在，随后全释放、尾音归零 |

完整演示24秒：0–1静音；1–4音色；4–7音量；7–11滑音/弯音/释放；11–15普通延音；15–18选择性延音；18–21力度；21–24八声部/全释放/静音。板卡顶层循环此序列。

三个音色是数学合成的实验音色，不宣称模拟了钢琴/管乐器。第三谐波等自然会比纯正弦明亮；白天定位原尖锐声仍用固定的单声部诊断工程，避免把主动增加的谐波混进原故障对照。

