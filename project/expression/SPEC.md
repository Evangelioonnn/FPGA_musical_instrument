# M3 表达控制与八声部扩展规格

2026-09-18夜间自主开发批次。仅软件/数字验证，原音质问题留待板测；既有test/audio_probe/instrument/audio_quality/audio_format/polyphony的源码和产物保持不变。此目录是可独立回归的候选集成工程，不覆盖比赛主工程。

## 执行顺序与完成标准

1. 参数化4/8声部管理，加入延音踏板、选择性延音(sostenuto)、确定性抢占与全释放。
2. 三种数学合成音色、持续发声时平滑切换、每音符力度、完整精度包络及混音后总音量。
3. 保持音符身份的实时重定音、可关闭的滑音和全局弯音比例。
4. 统一参数写入/应答、状态快照和音量峰值，为交互/通信队友提供接口。
5. 独立模型、模块/集成/串行验证、参考WAV与数字分析、Gowin综合/PnR/资源/时序，最后写早晨验收说明。

完成定义分为RTL测试、内部时序和实际板测。本批次不将未测的外设/音质标为通过，也不自动下载。新增引脚为零，复用原PT8211与CST/SDC。

## 统一边界

50MHz单时钟，同步高有效rst，sample_ce是时钟使能；实际Fs=50MHz/1040。连续音频管线要求sample_ce间隔至少16系统周期。默认8声部，同时编译/验证4声部配置；每声部独立相位和ADSR。

音符接口：event_valid/ready；kind=0 note_on，1 note_off，2 retune，3保留并忽略；note为原始7位音符身份，value为retune目标7位音符，velocity为0..256的9位线性幅度，超过256钳位。velocity=0的note_on按note_off处理。同音重触发原声部；重复来源的同音按键须由上游聚合，当前不内建输入源计数。

retune只改变占用声部的目标音高，保留原身份/相位/包络；例如on60、retune(60,67)、off60能正常结束。它可用于滑音控制；本版不实现单音键盘最后按键优先或自动连奏策略。

管理器优先分配同音、最低编号空闲、最早触发的真正释放尾音、最早的踏板保持音、最早的持键音。每次on更新相对顺序等级，无绝对时间戳回绕。被抢占的旧off不能关闭替代声部。on/off脉冲在事件接受后下一周期进入声部。

延音：踏板为1时松键不进入RELEASE；踏板落下不重新拉起已在RELEASE的声音。选择性延音：sostenuto上升沿锁存当时held的声部，后按音不加入；与普通延音取或。同周期新on不算此前held集合。踏板抬起且未持键/未被另一踏板保持时释放。全释放优先、ready低，清除held及踏板锁存并释放全部，不受脚踏状态阻碍；踏板继续保持高时不自动重新锁存。

## 声音与数值

波形使用三个独立相位地址的1024点数学正弦ROM（基频/2倍频/3倍频，同一声部共享基相位）：音色0纯正弦；1为3/4基频+1/4第三谐波；2为1/2基频+1/4第二谐波+1/4第三谐波。不是PCM录音或真实乐器采样，暂不命名为真实钢琴/笛子音色。

第二/第三谐波各自低于Nyquist时才加入；被抑制的权重归回基频。该保护不等于完美无混叠，查表误差仍在，高音跨谐波开关边界不保证无瞬态。两项谐波权重从0..16384、每采样以32步长接近目标，基频补足总权重65536，持续切换不重置相位/包络。

波形→16位无符号ADSR→9位力度→signed16声部。求和扩位，固定除以声部数量(支持4/8)，再乘总音量Q16[0,65536]、最终监测衰减64倍，饱和到signed16。先保留声部精度，避免原M2每路提前低幅量化。正式耳机声压仍未测定，不依此提高板卡增益。

总音量目标每采样以128步长靠近，满程约10.65ms；关音到0时必须精确归零。它是幅度控制，不等于响度线性或dB旋钮；需要对数手感时上游另做映射。音量/音色平滑时间不作为音符按下事件的延迟。

每声部note_on快照attack/decay/sustain/release参数，后续修改默认仅作用于新on/retrigger，防持音包络突然跳变。沿用M1 ADSR核心，retune不重触发。抢占保持相位/包络，不宣称无点击。

音高：基准音符相位步长乘全局bend_ratio Q16（32768..131072，半频至倍频），结果钳位到0x7fffffff，保护基频Nyquist。每采样current_step按glide_delta最大变化趋近目标；delta=0立即追随。新空闲声部首音直接到目标，重定音/持音弯音用滑音。滑音为线性频率斜率、不是等音分曲线或固定时长；时间由频差与delta决定。相位只按sample_ce累加，retune和音色变化不清零。

## 参数与反馈

cfg_valid在!rst时每周期接受一条，cfg_addr和cfg_data同步稳定。应答给出合法性及实际采用值；非法地址/越界值拒绝，不部分写入。

| 地址 | 参数 | 范围/默认 |
|---|---|---|
| 0 | master_volume | 0..65536，默认65536 |
| 1 | timbre | 0..2，默认0 |
| 2 | bend_ratio | 32768..131072，默认65536 |
| 3 | glide_delta | 0..0x7fffffff，默认0 |
| 4 | sustain pedal | 0/1，默认0 |
| 5 | sostenuto pedal | 0/1，默认0 |
| 6 | all_notes_off | 仅1合法，一周期释放脉冲 |
| 7/8/9/10 | A/D/S/R | 1..65535、1..65535、0..65535、1..65535；默认68/6/32768/3 |

同周期音符与参数写入，音符采用该上升沿之前的管理器输入；声部在收到注册on时快照参数。需要明确先后时上游先写参数、等待应答，再发送音符。所有多来源优先级由上游仲裁，本版不实现蓝牙/本地仲裁。

反馈提供occupied/held/踏板锁存、音符/目标音符、各声部包络与相位步长、current_gain、当前谐波权重、峰值和削波。统计快照默认每1024个有效样本更新，包含最后样本、窗口最大绝对值和削波保持；无ready反压，慢消费者可读取最新快照。它是显示接口，不含LED/屏幕/蓝牙物理驱动。
