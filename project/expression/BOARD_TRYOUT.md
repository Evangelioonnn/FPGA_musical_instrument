# 现有板卡上的首次表达效果验收

2026-09-18。用户已完成电脑试听与首轮板上试听，音量静音、力度变化和八音和弦获得主观认可；延音段噪声和突音仍需处理。音色最终另选，保留原 instrument 的纯正弦音色。详细结果和新旧差异见 `reviews/FIRST_BOARD_REVIEW.md`。

## 本轮使用已有产物

下载文件：仓库内生成的 `project/expression/impl/pnr/expression.fs`；Git不带该二进制，需先运行对应构建脚本。

本日复核 SHA256 为 `34246eb8eb45ef4cb30f0a4221181fe4013ae65e848990b910b1b4f53e065c4b`，与通过验证的构建记录一致。RTL、约束及比特流均未在本轮更改，无需重新综合。

这是真实 FPGA 逐样本合成：顶层自动发送音符与参数事件，不播放 WAV。只需现有板卡、DEBUG-USB2 数据连接和 3.5 mm 耳机，无需矩阵、编码器、FSR 或示波器。现在可以验证声音变化顺序、静音、滑音、释放和复音；音质、整机输入延迟、真实按键与踏板手感不能据此验收。

## 下载操作

1. 沿用此前耳机测试已成功的供电和 DEBUG-USB2 接法。若需重新插耳机，先断电插好再恢复供电；首次听时先把耳机放在耳边外侧确认音量。
2. 打开 Gowin Programmer，沿用已成功的 USB Debugger A 和器件 GW5AT-60B。
3. 编辑器件行：沿用此前成功的 SRAM 临时下载操作（通常显示 SRAM Program），File 指向上面的 expression.fs；不要选到旧工程的同类文件。本轮不需要 Flash 写入。
4. 执行下载，等日志显示成功。约 1 秒静音后开始发声，约 24 秒一轮自动循环。
5. 当前顶层未连接用户按键、PMOD LED 或 RGB 状态输出；不需要按任何按键。要重新对齐起点可再执行 SRAM 下载。不要把重新上电当作本候选仍在运行，因为断电会丢失 SRAM 配置并恢复 Flash 中的设计。

## 跟着时间表听

以下载完成后的自动序列开始计时，秒数为近似值。

| 时间 | 内容 | 检查什么 |
|---|---|---|
| 0–1 秒 | 静音 | 后续声响前有短暂等待 |
| 1–4 秒 | 同一 A4：纯正弦、加入第三谐波、加入第二/第三谐波 | 音高基本不变，音色渐亮；后两种主动加入的谐波不作为原杂音根因判断 |
| 4–7 秒 | 降到四分之一幅度、静音、恢复 | 5–6 秒音符应消失；模拟底噪可能仍存在。四分之一幅度不等于主观响度的四分之一 |
| 7–11 秒 | A4 滑到 E5、滑回、升两半音、回落并释放 | 连续音高变化，最后自然收尾 |
| 11–15 秒 | 普通延音三音和弦 | 12 秒起音，13 秒模拟松键仍维持，14 秒模拟抬踏板后衰减 |
| 15–18 秒 | 选择性延音 | C5 被保持，后来的 E5 松开后衰减，17 秒释放被保持的 C5 |
| 18–21 秒 | 相同音符三次，力度逐级增加 | 后一声比前一声强，次序清楚 |
| 21–24 秒 | 八音和弦、全部释放、静音 | 和弦能发声并完整结束，无卡音；仅靠听感不能证明八条独立声部均正确 |

电脑 listen WAV 放大了 32 倍，板卡比特流仍为低监测幅度；不要要求两种设备听起来同样响。当前不提高板卡增益来掩盖杂音。
