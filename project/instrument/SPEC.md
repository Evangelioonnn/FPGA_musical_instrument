# M1：单声部 DDS + ADSR 验证规格

状态：开始实现；板上验收待用户试听。本工程是比赛工程的起点，保留 test/audio_probe 基线。

## 硬件与时间基准

- GW5AT-LV60PG484AC1/I0，Version B；50 MHz / V22。
- PT8211 LSBJ：每声道 20 BCK，4 个前导零 + 16 位二补码，MSB 先发；WS 低=右、高=左。BCK=50 MHz/26，样本率=50 MHz/1040=48076.9230769 Hz。
- 输出引脚/电平沿用 audio_probe：Y17/AB17/AA16/AB16，PA_EN=0。
- 唯一内部时钟 sys_clk；sample_ce 是每 1040 个时钟一次的使能，不作为时钟。
- 上电复位保持 16 个系统时钟，由显式初始化计数器产生；输出初始静音。

## 模块契约

1. `pt8211_tx`：接收 signed 16 bit 左右样本；在 sample_ce 所在上升沿同时锁存，完整一帧保持不变；sample_ce 在正常运行时每 1040 个周期产生一次。时序由已验证 audio_probe 提取，不改变帧格式。复位会清零帧计数和输出。
2. `note_table`：7 bit MIDI 音符编号 0..127，组合输出 32 bit 无符号相位增量，按 A4=440 Hz 十二平均律和实际采样率生成。表是频率参数，不是预录 PCM。
3. `adsr_envelope`：16 bit 无符号包络 0..65535；状态 IDLE/ATTACK/DECAY/SUSTAIN/RELEASE。事件与 clk 同步，note_on/note_off 为一个系统周期的脉冲，不要求与 sample_ce 同时；事件优先于采样更新，同时 on/off 时 on 优先。重触发从当前包络进入 ATTACK，不突然清零。off 从当前值进入 RELEASE，IDLE 中 off 无作用。
4. ADSR 参数以每采样增减量表示：A=68，D=6，S=32768，R=3；约 20.05 ms 起音、113.61 ms 衰减、从 S 释放约 227.2 ms。运行期参数本次固定；零步长按 1 处理，边界饱和，不能环绕或卡死。
5. `synth_voice`：事件接口同上；note_on 或 pitch_we 锁存 phase_step，pitch_we 只变调不重触发包络。32 bit 相位每采样更新，变调与重触发保留相位连续；同步 1024 点 signed 16 bit 正弦 ROM，包络乘法后固定衰减。sample_ce 后第 3 个系统时钟输出新样本并置 sample_valid 一个周期；输入事件同采样沿发生时，包络从下个采样推进。输出范围 -512..511，不代表实测耳机声压。
6. `demo_events`：仅产生音符控制事件。六个约 1 s 槽循环：静音、C4(60)、E4(64)、G4(67)、C5(72)、静音；发声槽开始触发，约 0.65 s 松开，释放后归零。没有录音数据。
7. `instrument_top`：连接以上模块。核心本帧开始计算，输出器下帧锁存，增加一个采样帧固定等待；左右使用相同样本。本阶段无外部演奏输入，无复音。

## 必须通过的验证

- DDS：MIDI 0..127 的控制字与实数频率参考误差；C4/E4/G4/C5 的音频过零频率；正弦样本与解析 sin 参考误差；持续音中 pitch_we 后相位连续且包络不重置。
- ADSR：各阶段时间/单调性/上下限；短按、长按、Attack 和 Release 中重触发；同时 on/off；零步长；从任意阶段 off 后最终静音；sample_ce 之外事件不丢失。
- 输出：sample_valid 延迟、初始/释放后静音、正负幅度上限；PT8211 独立接收器检查位序、左右声道、前导零、20 BCK/声道、260 ns 半周期和数据建立时间；不同左右测试值以及帧内输入改变不能撕裂帧。
- 集成：真实 50 MHz 时钟及缩短事件间隔的完整循环串行解码；另以加速采样使能运行真实事件/包络采样数，导出核心样本分析六秒音高/音量包络/静音段。自动事件程序不替代之后的按键到声音延迟实测。
- Gowin 综合/PnR、50 MHz setup/hold、资源/警告记录；SDC 当前仅定义内部时钟，DAC 板级时序仍需专门约束/仪器验证。
- 板上：SRAM 下载后双声道相同、四音循环、起落自然；由用户确认，不能由仿真替代。
