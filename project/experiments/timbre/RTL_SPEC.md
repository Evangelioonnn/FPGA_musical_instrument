# FM / 拨弦单声部RTL任务 · 2026-09-19

用户已认可两份离线候选，授权同时开展FM和拨弦的单声部定点实现。分支`feat/fm-pluck-rtl`，起点`cac8fe0`（依赖system v0任务分支），角色A。范围：project/experiments/timbre、对应证据和状态/接口说明。原instrument默认声音与既有整机音频路径不改；本轮不实现整机音色选择、多声部新音色或32声部时序优化。

## 共用边界（fm_voice / pluck_voice）

- 50MHz clk，同步高有效rst。sample_ce默认每1040时钟一次，Fs=50MHz/1040；每次有效采样在不超过64个系统周期后产生一个sample_valid和16bit有符号sample。内部运算可流水/时分，不用软核，不播放录音PCM。
- 输入：cmd_valid、cmd_kind[1:0]（0=note_on，1=note_off，2=panic，3=保留）、note[6:0]、velocity[8:0]（0..256，>256钳位）、seed[31:0]（拨弦激励用；FM可忽略）。输出：cmd_ready、cmd_rejected（接受非法事务时一周期）、active。
- 只在cmd_valid && cmd_ready时接受；反压时生产者保持全部字段。note范围36..84（C2..C6）；范围外note_on和kind3明确拒绝且不改变现有音。velocity0的on按off处理；off/panic不要求匹配身份（单声部适配层接口，音符身份由将来上层管理）。
- note_on锁存音号/力度并重触发；优先级rst > 已接受合法命令 > 普通采样推进。note_off开始自然释放，panic立即取消正在初始化/运算并从此静音；复位后不可读出未初始化RAM。初始化/忙状态处理和具体延迟由各模块说明。
- 板级仅5个已知音频/时钟IO，复用instrument CST/SDC；演示顶层加固定监测衰减，使新音色板级数字幅度不高于原单声部约±512。算法原始音频和监听幅度分别记录。默认回归及噪声排查仍用原instrument。

## 算法与验收

FM参照已认可的双算子1:1相位调制、6ms起音、1.15s衰减、160ms调制深度衰减，初始index=1.2+1.8*velocity，原离线幅度系数0.13。拨弦参照噪声激励、分数延迟、两点低通反馈0.997，幅度系数0.24；确定性硬件激励可替换NumPy随机发生器，不能要求不同噪声逐点相等。

必须交付：RTL、必要数学表/生成脚本、独立Python数值/物理期望、ModelSim测试与采样导出；音准（低/中/高音，目标≤5音分）、包络/释放归零、力度、范围拒绝、重触发/复位/初始化、最大运算时间与整数饱和检查；FM与浮点参考误差，拨弦用相同激励浮点对照并检查谱形/衰减。逐样本RTL声音不能拿离线算法音频冒充。

最终分别Gowin综合/PnR，记录资源/时序、已知PR1014和实际.fs哈希。电脑试听与板级未验收分开记录。共有事务接口不表示已经接入现有system_core的每声部音色选择。

## 完成本轮后的具体时序

FM计算16周期，普通命令只在idle且sample_ce=0时接受；拨弦计算12周期，初始化最坏2946周期（58.92µs），初始化期间按每次sample_ce返回零。两者panic随时ready并将未完成采样结束为一个零结果，复位可丢弃在途采样。重复off/on0不重启释放。详细行为见各自README；最终数字验证、资源和仍待板测内容见[本轮证据](../../../evidence/timbre_rtl_2026-09-19/README.md)。
