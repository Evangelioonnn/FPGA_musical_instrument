# FM 单声部定点实验

本模块逐样本实现用户认可的 FM 电钢琴/钟琴方向。这里是 **1:1 双算子相位调制合成**，不是钢琴采样，也不声称对真实电钢琴的精确物理建模。原 `instrument` 默认音色完全独立；本模块尚未接入 `system` 的音色选择与复音管理。

任务分支 `feat/fm-pluck-rtl`，起点 `cac8fe0`，角色 A；本目录的接口遵守[共用规范](../RTL_SPEC.md)。代码、数学表、生成脚本、独立测试和参考音一起交付。板卡耳机尖锐杂音仍未定位，仿真声音正常不能代替板测。

## 数学与定点实现

设力度 `v=clamp(velocity,0,256)/256`、`t=n/Fs`、`Fs=50 MHz/1040`：

```
a(t) = (1-exp(-t/0.006)) * exp(-t/1.15)
i(t) = (1.2+1.8*v) * exp(-t/0.16)
y(t) = 0.13*v*a(t)*sin(2*pi*f*t + i(t)*sin(2*pi*f*t))
```

输出是 `y*32767` 的 16 位有符号 PCM，每个样本由 FPGA 计算。正弦 ROM 只存数学函数的 1024 个点；两个同步读口读取相邻点，用 16 位分数线性插值，避免简单取高位带来的阶梯误差。`tools/generate_tables.py` 可重建 ROM 和 C2..C6 音号相位步进表；生成结果直接初始化在 Verilog 中，不依赖仿真或综合工作目录下的外部 `.mem` 文件。

包络状态为 Q28，逐样本指数递推：`E -= round(E*k/2^28)`。6ms/1.15s/160ms 的 `k` 分别为 928965、4855、34894。调制深度直接用 32 位相位单位储存，最大 3 弧度小于有符号 32 位上限。32 位 DDS 在 50 MHz/1040 的真实采样率下计算音准；不能按精确 48 kHz 生成音高表。

主计算共享一个寄存的有符号 32×32 乘法器，多周期完成包络、调制、力度和输出。插值乘法为 9×17 位，单独流水。最终 Q24 输出对称舍入并饱和至 16 位；公式的原始数字峰值理论界限约 ±4260，力度超范围钳位，不通过每个音归一化改变力度关系。

本次1:1载波/调制器共享同一个相位累加器，符合已认可公式；没有两个独立可调频的相位状态。不能仅以“双算子”名称申报两个独立振荡器或两个声部，比赛吞吐计数需要按后续最终架构和官方定义另行核验。

`note_off` 用 7212 个音频样本线性淡出（约 150 ms），首样本增益为 1，末样本强制为 0。指数音色衰减在释放期间继续运行。重复 `off` 或 `velocity=0` 的 `on` 不会恢复释放增益。持续按住的音自然衰减；`active` 保持到释放完成或 panic，而不是把不可闻阈值当成松键。

## 时序与命令

- 同步高有效 `rst`；`sample_ce` 正常每 1040 周期。有效音的计算从请求至 `sample_valid` 为 16 周期，静音请求当周期返回 0。请求间隔须至少 17 周期；本实验没有为违反采样周期契约加入额外队列。
- 普通命令仅在空闲且 `sample_ce=0` 时拉高 `cmd_ready`。发送者保持命令字段直到握手；遇到采样或运算会等待，不丢当前样本。
- `note_on` 接受 36..84（C2..C6）；范围外或 `cmd_kind=3` 的事务以一个 `cmd_rejected` 脉冲拒绝，当前音不变。范围验证先于零力度处理，因此范围外的零力度 `on` 也拒绝。
- 有效 `on` 清零相位、重置包络、锁存音号和力度；`on` 的零力度相当于 `off`。`off` 不按输入音号匹配，身份匹配由未来的上层单/多声部管理器负责。`seed` 对 FM 无作用，保留共用接口。
- `panic` 在任何状态都可握手，立即令 `sample=0`、`active=0`，取消计算。如果有未完成采样或同周期 `sample_ce`，当周期返回一个零结果完成该采样；后续不能冒出旧结果。无未完成采样时不制造额外 `sample_valid`。
- 复位取消请求并清空寄存状态，不输出历史声音。正弦插值的内部旧结果即便在 panic 后自然跑完，也不能被采样状态机使用；下一个音重新发起查表。

## 可复现验证

在仓库根目录运行：

```powershell
& ./project/experiments/timbre/fm/sim/run.ps1 `
  -ModelSimBin 'E:/QuartusII/modelsim_ase/win32aloem' `
  -PythonExe 'C:/Users/lenovo/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/python.exe'
```

`PythonExe` 可替换为已安装 NumPy 的 Python。`run.ps1` 在本目录独立的 ModelSim `work` 中编译，不占用其他实验的库，失败或未出现 PASS 都退出报错。

`fm_control_tb` 检查范围/保留命令拒绝、重触发、力度钳位、重复松键、反压保持、释放归零、复位，以及 16 个在途运算阶段逐一 panic。`fm_numeric_tb` 导出真正 RTL 计算的原始有符号样本；Python 用已认可的 **闭式浮点公式** 对照，不复制 RTL 递推或整数查表来制造相同答案。

数值场景包括 36..84 的全部 49 个音、C2/C4/C6 晚段频谱估计、零/最小/中/满/超范围力度、3 秒持续音与释放、统一 7.5 秒单声部试听。渲染时压缩样本间空闲时钟以加速，指数与相位只按 `sample_ce` 推进；50 MHz/1040 的真实 PT8211 串行帧由上一级板级探针测试独立验证。

仿真生成的 `sim/fm_rtl_audition.wav` 是真实 RTL 样本；`sim/fm_float_same_score.wav` 是独立公式对照，不能互换标签。10 段均为单音：C3/G3/C4/E4/G4/C5，接一个 C4，再接三档 C4 力度。第 7 段是单个 C4，明确不冒充离线候选里的三音和弦。WAV 头为整数 48077 Hz，生成和分析仍用真实分数采样率，差异不到 0.000003。

完整分析写入 `sim/fm_validation.json`；永久验收摘要、试听和板级构建报告由上一级 timbre 实验统一归档。`sim` 的原始百余万行样本和临时库不提交 Git。新音色板级演示另加固定监听衰减；本目录试听保留算法幅度，不将耳机的低监听幅度冒充算法原始输出。

## 本轮数字结果（2026-09-19）

| 检查 | 结果 |
|---|---|
| 行为测试 | 范围/保留命令、重触发、力度钳位、重复松键、反压、panic、reset、释放通过 |
| 独立闭式公式对照 | 69 场景、1,092,390 个真正 RTL 样本通过 |
| 与未量化浮点式的误差 | 最大 0.97489 LSB，RMS 0.29649 LSB，误差 SNR 74.12 dB |
| C2 / C4 / C6 的晚段频谱音准 | 最大绝对偏差 0.000233 音分；这是仿真估计，未包含实物晶振误差 |
| 原始峰值 / 单声部试听峰值 | 4121 / 3704（16 位 PCM 幅度，无归一化） |
| 运算截止时间 | 发声 16 周期，50 MHz 下 320 ns；不等于整机输入到模拟输出延迟 |
| 模拟输出、耳机、真实输入 | 本轮尚未验收 |

数值误差门限为最大 3.5 LSB、RMS 1.0 LSB；音准门限为 5 音分。没有拿整数实现自己的计算过程当作期望值。所有 `velocity>=256` 的钳位检查逐样本一致，0/1/64/128/256 力度的 RMS 严格递增。7212 样本释放的末尾及后续全部严格为零。
