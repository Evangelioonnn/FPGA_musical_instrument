# 原音色长音诊断

三份工程只用原来的5个时钟/耳机IO，不需要外接输入。正确顶层和用途：

| gprj | Top | 每10秒循环 |
|---|---|---|
| `c4/lab_c4.gprj` | `lab_top` | 约1s静音→6s C4长音→自然释放→静音 |
| `a4/lab_a4.gprj` | `lab_a4_top` | 相同时间、A4=440Hz |
| `silent/lab_silent.gprj` | `lab_silent_top` | 数字零样本，仍发送BCK/WS/DIN |

原voice、电平、ADSR和PT8211格式保持不变；单声峰值约±512，保持约±256。便于把随音高变化的杂声与固定开关/电源干扰分开定位。仿真A4/C4参考音在[evidence/audio](../../evidence/README.md)，这不是板卡录音。

构建例：仓库根执行 `gw_sh.exe project/lab/c4/build.tcl`。对应.fs在该子目录impl/pnr，本轮未自动下载；以[构建指纹](../../evidence/system_v0_2026-09-19/builds.json)核对本机文件和工程。使用Programmer的SRAM下载，不需要覆盖Flash。

## 双通道示波器安排

具体可触及位置沿用已核对的[定位图和步骤](../audio_quality/NOISE_DIAGNOSIS.md)，不要把FPGA封装球号当可直接夹探头的位置。数字网名：BCK/Y17、WS/AB17、DIN/AA16。探头地夹只接板卡GND，不能夹耳机左右声道/功放差分端。

1. 先C4：CH1=BCK、CH2=WS。预期BCK约1.923077MHz，WS约48.076923kHz，每声道20个BCK；记录高低电平和周期。
2. CH1=BCK、CH2=DIN，看数据在下降沿变化，离上升沿约260ns；配合长存储检查每字4个零填充+16bit有效数据。仅看到“有波形”不代表数值正确。
3. 可安全接触的DAC单端模拟输出对GND，与耳机输出分别观察C4/A4。需要判定失真是否在DAC前后出现；没有安全测试点时先停在数字测量，不用探头尖跨接细脚。
4. 纯静音时测底噪，再用同增益/同量程的C4、A4比较附加谱线是否随音高变。保存原始采样/示波器文件、探头倍率/耦合、供电、实际.fs SHA和耳机条件。

结论规则：FPGA引脚串行正确只定位到输出端，不能证明DAC采样、PT8211电源/参考、功放及耳机负载均正确；反之仿真正常也不能直接判定板卡硬件损坏。
