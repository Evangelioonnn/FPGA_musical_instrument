# Looper候选功能与数值契约

2026-10-07改进候选；数字证据见[VALIDATION](VALIDATION.md)，板测待用户验收。

## 时钟和全局节拍器

50MHz；Fs=50,000,000/1040=48,076.9230769Hz；96 PPQN。BPM 40～240钳位、默认120、每格1 BPM；2/4、3/4、4/4，分母固定四分音符。控制器只允许Looper停止时改拍号/循环长度，循环长度1～4小节。

累加器每帧加 `BPM×96×1040`，阈值3,000,000,000，越界保留余数。不用整数除法截断每拍长度。恒定BPM时第k拍为 `ceil(k×3e9/(BPM×1040))` 个音频样本，算法误差不超过一帧（20.8µs），不累积舍入漂移。实物还受50MHz晶振误差影响，本轮未测晶振ppm。

启动立即第一重拍；静止时关节拍器，时钟停止；Looper运行时关点击只关闭声音，循环相位继续。Looper启动重对齐，包含一完整小节预备拍，预备拍强制有声。BPM在下一拍边界生效；拍号在停止/重启或小节边界应用。

点击独立相位/包络，480样本约9.98ms，强/弱拍约2kHz/1.5kHz，不占旋律或鼓槽，不录音、不进房间效果/延音。增益无符号Q8 0～256、默认96，1 LSB/样本平滑；仍受主音量/全局静音控制。

## 轨、层和生命周期

四循环轨＋独立现场来源。每轨4层，每层128事件，共2048；一次按下/松开通常占2事件，鼓击打占1。满层不覆盖旧层；事件/活动实例溢出取消整次take并置故障。新take使用选中轨首个空层；撤销清除最后有效层，清空只影响选中轨。取消当前take不影响已提交层。

停止/撤销/清空给相应循环旋律发松键，给相应鼓尾音短释放，不对现场持续音发全局panic。停止后允许自然尾音，不是立即归零。录音未松实例在最终tick补松键。末拍事件及缓冲先排空，再补松键/提交，避免回绕盖掉时间戳。

时间戳在现场路由捕获时锁存，不随bank延迟或播放回绕改变。量化只影响记录/回放，不延迟现场。关闭/48/24/12 tick四档；四舍五入至最近网格，末端钳位 `loop_length-1`。同tick优先松键再开音；阻塞事件整包保持到握手消费。

回放 `(track,layer,local_id)` 映射唯一32bit运行token，同音高不合并。bank接受后才建立有效映射，拒收不留幽灵held。鼓满载消费并报告拒绝，不录入未接受的现场击打。循环满载拒收会影响音乐结果，需要用户避免超过容量；不偷音。

## 音色和冻结参数

ID固定：0钢琴、2 Warm pluck、3铃音、4 Drive lead、5自定义、6鼓组。每层一个patch，**在实际record_start而非按录音键/预备拍开始时捕获**。下一层可以换音色，四轨可同时含多种乐器。录音中改现场音色/系数会改监听，但当前层回放仍用开始patch；换音色建议新层。

四谐波无符号Q8 0～256，256=1，默认 `[256,64,32,16]`。旋钮模拟0～4095原始推子，经既有服务映射、平滑到应用Q8值；捕获应用值而非未收敛目标。循环系数/ADSR冻结，每层记录自己的普通/选择性延音及有界弯音，不受当前现场踏板污染。Loop Lead冻结glide/attack，滑入源限同轨。颤音深度/速度和连续四谐波编辑暂不录入。

| 136bit patch位 | 内容 |
|---|---|
| 2:0 | 稳定音色ID |
| 14:3、26:15、38:27、50:39 | 各12bit字段零扩展存9bit应用Q8系数 |
| 66:51、82:67、98:83、114:99 | 16bit A/D/S/R，既有包络单位 |
| 117:115 | release档，映射96/48/24/12/6/3/2/1 |
| 119:118 | Lead起音档 |
| 122:120 | Lead滑入档 |
| 123、124 | envelope_override、custom_hold |
| 135:125 | 保留0 |

事件RAM实际每条45bit：11:0 tick；13:12 kind（0开音、1松键、2鼓、3控制）；20:14 note/pad；36:21 local_id；44:37 velocity。旧64bit的19个保留位原先已被Gowin裁掉，修改声明不单独声称省RAM。不存PCM。

kind3时note[1:0]是opcode：0普通延音、1选择性延音、2弯音；值为 `{velocity[0],local_id}` 的17bit。踏板0/1，弯音无符号Q16，65536为unity，正常来源范围58386～73562。kind1的velocity=0标记边界补松/强制释放，普通松键为255。

非鼓take初始化录3个tick0控制事件；踏板每音频帧观察，弯音最短1200帧（约24.96ms、最高约40Hz），变化阈值256 Q16。表达也使用该层量化档、保持单调顺序。8项FIFO、寄存事件出口、32槽录音note身份查找约34时钟；阻塞时稳定，溢出取消take、不覆盖旧层，下一take可恢复。控制也占128事件，长循环连续弯音可能耗尽容量；这不是无限自动化轨。

选择性延音只锁住该track/layer当时已按下的合适音。停止/撤销/清空复位相应层控制，边界补松绕过延音。只有初始化控制、没有旋律击键/鼓击打的take不占层。

真实四谐波服务将总应用系数限制到368，包含平滑途中；四根原始4095请求先映射256再归一化为[92,92,92,92]。CH0是后混音主音量，原始0为既有安全静音接管，优先于普通pickup。矩阵力度固定255，字段存在不代表已实现逐键力度。

## 复音、混音和上界

旋律32共享槽（含尾音），Warm pluck物理12计入32；鼓8独立槽。现场和所有层共同争用容量，四谐波不乘四申报振荡器。循环轨音量Q16 0～65536=0～1，静音/调节每样本变化≤128；现场不乘轨音量。主音量后置Q16≤unity，无活跃声部数归一化。

32槽是同时占用上限，不保证每轮32音和弦在保留上一轮尾音时仍可全部重触发；Warm pluck的12槽也包含旧尾音。循环占满后现场新音可能拒收。应给尾音/现场留余量，密集叠录的音乐结果另验收，不能用一次满载渲染测试证明任意编曲都完整回放。

路径：各旋律轨增益→旋律混合/饱和保护→可旁路短房间→加鼓/点击→固定1/2总线裕量→平滑主音量→PT8211。鼓和/16，鼓与点击不进房间。

保守界：旋律限幅≤32768；8鼓各≤32768，和/16≤16384；点击≤7680；aux≤24064，总线/2≤28416。主音量≤unity，最终加法不再溢出。固定1/2令单旋律相对原V2低6dB，可提高主音量补偿，不能称电平不变。

在V2固定每音1/4基础上，自定义默认系数总和368，32同音保守界≤23552。真实受保护链路四根全满仍总和≤368，32同音保守界≤23552。`looper_custom_bound_tb N32/FULL1`故意绕过服务向bank直接注入256×4，其削波是非法内部注入诊断，不能描述成正常推子问题。独立实际参数/模式适配链测试32同音＋8鼓＋最大点击＋房间＋master unity，需按当前JSON核对无clip/超时和峰值；不以数字界替代模拟测量。

## 鼓垫顺序

key0～15：底鼓、军鼓、低筒鼓、中筒鼓、高筒鼓、闭镲、开镲、吊镲1、吊镲2、Ride叮叮镲、Ride bell、脚镲、拍手、边击、牛铃、沙锤。底鼓/筒鼓下降音高正弦，军鼓正弦＋噪声，镲片噪声＋金属方波，独立衰减。有空槽时闭/脚镲使用新槽、开放镲每样本减128淡出，最坏约10.7ms；满池时允许复用被choke的开放镲槽，仍有重置突变边界，不偷其他鼓。待实物听感验收。不播放样本，不宣称复现Mutable Instruments音色。
