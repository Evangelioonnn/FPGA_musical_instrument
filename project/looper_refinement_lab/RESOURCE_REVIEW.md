# 本轮资源结论与整合优先级

本轮保留声音精度、事件容量、32共享旋律/12拨弦/8鼓及C预留。精确数字见 [VALIDATION](VALIDATION.md)；团队总账仍只维护 [RESOURCE_BUDGET_V1](../../docs/team/RESOURCE_BUDGET_V1.md)，本页不建立第二份额度。

净省11 BSRAM/2 DSP，增加1215 Logic/821 Register/893 CLS。四分之一正弦表已经有4096地址及默认PCM等价证据；45bit事件声明只是去掉原已被综合裁剪的保留位，不将它计作新存储收益。

## 两个不同的物理问题

独立19针实际20ns报告最差setup为0.018ns，起点为 `platform/audio/bank/release_next_0_s`，经拨弦内存/控制逻辑至 `plucks[3].slot/pluck_path.pluck/sample_14_s1`。这是后续流水化释放参数或缩短选择链的具体审查对象。若改变流水线，必须保留默认PCM对照、实时参数、起音/松键/满载期限与全部回归，不能只看Fmax。

接口默认20ns布线失败333网，未获得合格STA/FS。其PRIMARY/LW都8/8，多条voice_rst副本被自动提升到全局网；它提示复位分发可能影响布线，但不证明所有失败网都由复位导致。基础LOCAL_CLOCK候选失败272网；加入真实PLL拓扑的最终审计失败3402网，CLS26449/29952，PRIMARY/LW仍各8/8，没有合格STA/FS。只调整根复位路由或换PLL均未解决问题；不继续把它描述为单一已确诊根因。精确负证据见VALIDATION。

## 后续整合路径

1. 取得C当前已验证的固定源码、PLL和实际资源报告，先把真实最小控制台与音频接在一起。不得用旧彩条或本审计digest代替她的UI测整机。
2. 优先优化完整快照的选择/复制与bank状态访问，尝试分时/分组访问或更多利用空闲DSP；同样的信息与精度必须保留，不能删字段、压音量或缩减声部来包装收益。
3. 以实际关键路径决定流水化位置，并检查高扇出复位/使能和CLS打包。当前较空闲的DSP不代表布线或Clock/CLS自动有余量。
4. 优化后重新整机PnR、CDC、满载期限及当前源回归，再考虑tap/细分或额外声部。本轮不提供无资格40槽固件。

单独模块的CLS并排相加是保守风险估算，联合布局有可能复用空LUT/寄存器位置，也可能受时钟/复位/布线限制；不能据此证明一定放不下或一定可用。C13k Logic/10k Register/26 BSRAM/16 DSP/1 PLL预留不减少。
