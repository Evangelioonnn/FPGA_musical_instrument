# 矩阵可演奏候选：一份固件，三个音色

本轮目标为八声部真实矩阵 + EC11 + 底板三用户键。原默认正弦DDS/ADSR、拨弦、FM在同一工程切换。**真实矩阵接线、操作手感和音质仍待用户板测，历史尖锐杂音未被认定修复。** 构建结果和命令见[验证记录](VALIDATION.md)。

先看[接线](WIRING.md)，再使用本目录 `matrix_playable.gprj`。Designer重新打开工程，确认顶层 **matrix_playable_top**；不是playable_bank、playable_engine，也不是其他旧演示。
本机完整构建生成 `impl/pnr/matrix_playable.fs`，下载选SRAM。本轮不改板卡Flash。仓库不提交该大型比特流，可用源码重建。

## 怎么操作

| 控件 | 动作 |
|---|---|
| 矩阵S1..S16 | 半音阶C4..D#5；按下发声，松键行为取决于音色 |
| 底板USER_BUTTON2/S1 | 原默认→拨弦→FM→原默认，每按一次切换 |
| 底板USER_BUTTON1/S2 | 普通延音开/关，作用于原默认和FM |
| 底板USER_BUTTON0/S4 | 短按松开切换旋钮音量/尾音模式；长按1秒平滑止音并清延音 |
| EC11 | 音量模式每格3dB，最低档静音；尾音模式每格切换长度档位 |

上电默认：原默认音色、音量满幅、延音关、旋钮音量模式，原音色尾音参数R=3。切换音色不会截断已发出的旧音；旧音松键按原来的独立身份释放。同一键快速重弹保留旧尾音。最多八个实例同时占用；满载拒绝新音并橙灯提示，不降低已有每个音的音量、不抢走响着的音。

拨弦默认完整自然衰减，松键、普通延音和尾音旋钮不改变它。拨弦尾音模式黄闪表示该控制不适用；音量仍有效。FM保留自身自然衰减，延音只推迟松键释放，不能把已经衰减的声音无限维持。

原默认和FM分别保存尾音设置，进入释放时锁定：调整旋钮会影响之后开始的释放，正在消失的尾音保持原设置。原默认可调约数毫秒至最长约1.36秒（实际由松键瞬间包络电平决定）；FM档位约30/60/100/150/300/600/1000/2000ms，默认150ms。

板载RGB：蓝=原默认、绿=拨弦、紫=FM；尾音模式慢闪；延音开启加亮；拨弦不适用尾音模式黄闪；满载短暂橙色；鬼键/恢复等待红色。启动需要全松，红灯恢复时把矩阵所有键松开再弹。

## 首次验收顺序

1. 断电按WIRING接线，上电全松，SRAM下载后确认状态灯。
2. 默认音色按S1、S2、S5，核对行列和音高；长按、松开、快速重弹。
3. USER_BUTTON2每次切一个音色，重复前一步；拨弦即使短按也应自然响完。
4. 三音色分别转动旋钮调音量到静音再恢复；静音时操作不应产生新的突发声。
5. 原默认/FM测试短尾/长尾、延音开关；拨弦保持原本自然音色。
6. 音符还在响时切换音色后按另一个键，旧音应继续；快速重弹听尾音叠加。
7. 长按USER_BUTTON0止音；松开所有矩阵键后重新弹奏。
8. 最后测试已知鬼键组合S1+S2+S5，观察红灯和全松恢复。不要把鬼键保护误认为音频复音引擎只能发两声。

反馈分别记录“电脑参考”“板卡主体”“新增突音/尖锐声/底噪”。这版不以更换音色或平均缩小复音音量来掩盖杂音。

## 以后怎样复用

- `playable_button`/`playable_controls`：独立按键与面板参数；产品可以换控件，保留参数含义。
- `playable_keys`：快照排队、32bit音符实例、对应松键、故障恢复。
- `playable_bank`/`playable_slot`：独立实例分配、三音色生命周期、固定增益混音。
- `playable_engine`：上述模块与音量平滑、紧急静音的集成。
- `matrix_playable_top`及CST：仅本次板卡接线；不能直接作为B最终控制板的约束。

接口详见[SPEC](SPEC.md)。没有接入蓝牙/外屏/压力，没有替换SYSTEM_V0契约，后续由A统一迁入主工程。回声和选择性延音按用户决定暂缓。完整ADSR面板、单音实时变调和最终端到端延迟仍要单独验收。
