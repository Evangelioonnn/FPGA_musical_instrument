任务：2026-09-21，A；分支 `codex/matrix-playable-v1`，起点 `f9bcd79`。
允许目录：新增本目录，必要的 docs、evidence、仓库检查入口；既有音色/演示保留。
目标：一份八声部三音色固件，真实矩阵/EC11/三个板载用户键；只做本地实现与验证，不烧写Flash。

## 音乐行为

- tone 0：原 instrument 正弦 DDS，默认 ADSR=68/6/32768/3；松键释放，支持普通延音。
- tone 1：原 pluck 数学模型/种子/电平，一次按下自然衰减；松键、延音、尾音旋钮均不重新激发或延长它。
  原始输出连续4096采样小于一个板级量化步（abs(raw)<32），且已发声至少12000采样，才回收。
  最长30秒保护随后走原150ms释放；该保护不是正常的固定音长。
- tone 2：原 FM 自然衰减，普通延音推迟松键释放；新增可配置释放长度，默认7212采样保持旧数学行为。
- 切换音色只影响新音。每次按下分配独立32bit身份，旧尾音不会被同音重弹覆盖。
- N=8，固定每声部电平：原音色不缩放，FM/pluck沿用 >>>5 并限幅[-512,511]。
  32bit累加，最终16bit饱和；不按活跃声部数量归一化。满载拒绝新音，保留原有声音并计数。
- 原音色 R 档为96/48/24/12/6/3/2/1，默认档5；FM为30/60/100/150/300/600/1000/2000ms附近的整数采样值，默认档3。
  两音色各自保留设置，释放开始时锁定；已释放尾音不受之后旋钮影响。
- 回声、选择性延音不接入。压力、蓝牙、显示、实时变调、全ADSR面板仍是后续工作。

## 时钟、事件与错误处理

50MHz单域；同步高有效复位。Fs=50MHz/1040；sample_ce间隔至少1040时钟用于真实板级。
模块算法加速仿真可用较大于最坏计算时间的间隔，初始化/串行验证必须保持真实时钟。

矩阵快照队列深8，存16bit键状态+2bit音色。队列按扫描变化顺序处理，快照内部先off后on。
事件：valid/ready握手；kind=0 on、1 off；token[31:0]、note[6:0]、timbre[1:0]。
载荷在反压期间稳定。on的token从1递增，0保留；禁止回绕，耗尽时故障保护，重新配置前不再演奏。
off引用按下时保存的token，与音高/音色切换无关；满载被拒的on对应off允许无匹配。
接口是新的实例事件候选，不悄悄替换 SYSTEM_V0 的按音号事件和快照。

无二极管矩阵：一行低，其余高阻，列内部3.3V上拉。使用已有扫描器，50us/行、8帧稳定去抖。
鬼键/快照溢出/紧急停止：停收事件、清快照及键归属，主音量平滑降到0，然后复位声部；清延音。
待音频清理结束且物理全松、去抖状态也全松后重新武装。静音后新按键才能触发。
不得通过单独丢弃off处理溢出。数字验证不等于实际机械去抖或<=10ms端到端测量。

## 面板

- USER_BUTTON2 / S1 / Y12：按下循环0→1→2→0。
- USER_BUTTON1 / S2 / AB13：按下切换普通延音；拨弦自身忽略踏板，仍允许控制旧音色尾音。
- USER_BUTTON0 / S4 / AA13：短按松开切换音量/尾音；长按1秒紧急停止，松开不再触发短按。
- 三键内部1.5V上拉、低有效，独立两级同步和3ms去抖；SW7 RECONFIG不参与。
- EC11保持A=T18/B=R17、3.3V、C悬空；音量24档+静音，默认满幅，沿用平滑增益。
- 拨弦尾音模式旋转无音频参数变化，状态灯明确显示不可调状态。
- 板载WS2812 J16：蓝/绿/紫指示默认/拨弦/FM；尾音模式慢闪，拨弦不可调模式黄闪；延音加亮；故障红、满载短暂橙色。

## 板级资源依据

NEO Dock Rev1.4官方图纸第7、9、19页；IO方向/电压以实际CST为准。
PMOD1为J8（与旋钮的PMOD0/J9分开）；IO0..7=Y21,Y22,AB21,AB22,AA20,AA21,AA19,AB20。
矩阵商品上半原理图针1..8=C4,C3,C2,C1,R1,R2,R3,R4；按此接J8 IO0..7。
商品下半PCB示意针序存在差异风险，首次单键辨识必须记录实物，不凭连接器朝向猜编号。
矩阵8根线都是信号，不连接PMOD的电源针。默认键S1..S16映射MIDI60..75。
列输入C1..4=AB22,AB21,Y22,Y21，行输出R1..4=AA20,AA21,AA19,AB20。
音频和时钟继承已板测约束，pa_en=0（已有功放使能值）；本轮以耳机通路验收，未验证扬声器负载。
