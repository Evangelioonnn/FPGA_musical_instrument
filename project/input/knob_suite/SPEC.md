# 旋钮演奏与控制候选 · 2026-09-20

任务分支 `codex/knob-performance-suite`，起点 `7a9ac41`，角色 A。用户授权本轮实现、仿真、构建、本地提交，并允许完成后尝试 GitHub 同步。范围为本目录、复用依赖的必要修正及对应接口/状态/证据；不替换已验收 EC11 探针，不使用未确认的 C/按压输入。

## 目标与验收

- 五个七 IO 顶层：逐格弹奏、主音量、三音色、释放时间、延迟效果。A=T18、B=R17，3.3V，C悬空，原音频与50MHz针位不变。
- 弹奏：每个合法卡点触发新的独立实例，同音高不合并；C3..C6饱和，到边界继续旋转仍重弹边界音。静止不发新音，上电静音。每实例持键31250采样后自行松键，原ADSR 68/6/32768/3自然归零。
- 基准16声部、三音色8声部是构建目标，只有通过对应PnR后才推荐下载。有限容量内不抢占，满载拒绝新事件且递增可观测计数，不假装无限复音。记录最大完整承接速率。
- 原音色直接复用 synth_voice。释放实验复用相同DDS管线、sine_rom和adsr_envelope，新增可锁存参数，并与原voice逐样本比较默认行为。
- 混音全宽累加、固定增益、不除以活跃声部数；原音色保留原±512码范围。FM/pluck沿用已试听的固定除32监测电平，不随复音变化。不提高既有新音色单音电平。
- 三音色选择仅影响新的实例。已有实例的音高、音色、ADSR和持键时长在触发时锁存。FM/pluck没有继承原正弦的ADSR参数，沿用各自算法与150ms释放。
- 音量、释放、音色、效果版本由内部实时音符序列驱动；旋钮只调对应参数。自动序列是事件发生器，非PCM录音播放。
- sustain/sostenuto/all_release 是逻辑测试接口，本轮没有踏板接线。选择性延音只锁存上升沿仍持键的实例；all_release优先释放所有实例，后续新音不受旧命令影响。
- 参数调节、事件处理与音频采样隔离。sample_ce=50MHz/1040。输出先完成所有声部结果，再快照/逐声部累加，提交给原PT8211发送器；保留左右相同。

## 复用接口

`knob_bank`：strike_valid/strike_ready握手，携带note[6:0]、timbre[1:0]、gate_samples[23:0]与A/D/S/R四个16位参数。ready只表示可处理事件；accepted/rejected下一周期区分实际分配、非法参数或满载拒绝。accepted_slot标识本次实例，生命周期到done；下一次分配可复用槽。没有按音高统一松键。输入必须在valid且未ready时保持稳定。

note限制48..84；tone=0原声、1拨弦、2FM，3拒绝；非MULTI构建只接受0。gate_samples=0拒绝。仅DYNAMIC_ADSR且tone=0支持非默认ADSR，其余情况传非默认值明确拒绝。无动态增益和隐式声部抢占。occupied/gated/sost masks、accepted/rejected/count、clip/deadline支持仿真与后续观测接入，不能引成板级额外IO。

all_release会取消尚未发声的已分配实例，已发声实例进入正常释放；它不自动清理上层事件FIFO。真正的整机紧急停止需要上层同时清队列。本接口尚无外部按键的逐实例note_off/身份令牌，是定时弹奏候选，不直接替代SYSTEM_V0。

`knob_slot`独立管理启动握手、持键计时、踏板锁存、释放和流水排空。拨弦初始化仅占自己的实例，不阻塞其他声音。默认主音量保持unity，音量实验采用固定刻度表和每采样平滑；效果量0时最终输出逐样本等于干声。

## 验证分层

1. 数字：旋转刺激、独立同音实例、自动松键与踏板顺序、满载/恢复、音量与混音独立数值期望、原音色精确回归、真实串行解码。
2. 参考音：来自RTL实际输出；原始电平和固定增益预览，禁止逐段归一化。不是板卡录音。
3. 构建：每个最终顶层资源、7个IO、50MHz setup/hold、源码及bitstream指纹。32声部历史失败不作本轮达标证据。
4. 人工：实际旋钮操作、耳机听感、模拟延迟待用户验收；原尖锐噪声继续单独定位。
