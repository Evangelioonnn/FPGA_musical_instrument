# 输入适配候选

9月21/22新增[matrix_playable](matrix_playable/README.md)：一份八声部三音色矩阵/旋钮/板载键固件，逐实例松键、自然拨弦和故障恢复；数字/PnR已通过，音频证据整理与实物验收状态见[STATUS](../../docs/project/STATUS.md)。接线在其WIRING，不能直接沿用旧input_audit的逻辑端口。

这里的扫描、去抖、键位路由、EC11 和数字压力表达模块已经有独立 RTL 仿真；它们只接受已经采样的数字 ADC 总线，尚未假定 Tang Mega NEO 的 ADC 针位或外部器件电气连接。

`input_audit.gprj` / `build_audit.tcl` 是不带 CST 的综合资源审计，端口名只是逻辑边界，不能直接下载到板卡。B 提交控制板电气和 IO 提案后，A 才能建立带真实约束的整机顶层。

9月19日收到EC11，已新增[独立板级探针](ec11_probe/README.md)，按用户实接的A=T18、B=R17生成7个IO的音频测试固件。仿真/构建和用户旋转试听通过：3.3V供电、C悬空，快慢双向正常、一格一次、静止稳定。C/按压仍未识别，整机输入尚未接通。

9月20日新增[旋钮演奏与控制候选](knob_suite/README.md)：逐格独立音符与尾音叠加、主音量、三音色切换、释放时间和回声量，沿用同一四线接法。首次板测认可音量/释放控制及基础弹奏，但快转起音/转动切换音色有新增杂音，见[板测记录](../../evidence/knob_suite_2026-09-20/BOARD_LISTENING.md)。操作见[验收指南](../../docs/project/KNOB_REVIEW_2026-09-20.md)。

逻辑审计暴露全部配置/状态总线，共316个逻辑端口，超过板卡可用IO是预期现象；它只执行`run syn`，不能误选为板级顶层。综合结果1198 Logic、583寄存器、4 BSRAM，无DSP；尚无这部分的布局布线结果。

## B可以怎样使用

| 模块 | 当前默认行为 | 接硬件前要确定 |
|---|---|---|
| matrix_scanner | 4×4，50μs/行、8帧去抖；无二极管鬼键保护 | 行/列顺序、按键结构、每键二极管方向、上拉电压 |
| key_router/key_pipeline | 按下锁音号、松键可靠、同音合并；8份状态快照队列 | 最终布局与映射、输入RTL责任、不改变已持有键的约定 |
| ec11_input | Gray全步，4转移/格；AB约100μs、按钮约3ms稳定识别 | 当前实物旋转已板测每格一次；换模块重新核实，C/按压仍未知 |
| pressure_expression | 12bit数字输入，校准/死区、IIR、100ms超时归零 | 传感器分压、电压范围、ADC接口、采样周期/有效握手 |

矩阵输出`row_low`是逻辑掩码：1代表把这一行拉低，0对应外部行引脚高阻。非选中行不能主动拉高，避免多键导通把两个输出短接。实际三态/上拉放在最终板级wrapper；本模块没有绑定PMOD针脚。`HAS_DIODES=1`只在真实每键隔离二极管符合扫描方向时使用。

无二极管时，三角矩形可能形成鬼键，当前策略是释放并报错，**不是任意多键无冲突**；最终成品若要自由和弦，B需考虑逐键二极管、独立输入或等价可验证扫描硬件。

压力输出只是全局连续表达，不是逐键力度。数字过滤在1kHz采样时约数毫秒变化；ADC未采样/超时会让启用的表达归零。用户偏好的手势和放置位置仍由B论证，这份RTL不冻结“必须按压力板”的产品形态。

control_surface逻辑候选中EC11映射主音量，尚未完成该映射板测；独立ec11_probe板测映射音高。按压只在逻辑候选输出pressed，实物未绑定。具体映射、按键数和琴键/网格方案仍可更换；共享协议见[SYSTEM_V0](../../docs/interfaces/SYSTEM_V0.md)。

共享输入验证入口是 `project/system/sim/run.ps1`；矩阵测试含真正的行列连通模型，非只喂预期键码。EC11探针另有`ec11_probe/sim/run.ps1`。其余外设到货后先核对电气、接线和单键/压力；每项记录实际板测和供电条件。
