# 七份固件试听与双区验证

沿用 final_dual_timbre 已验证接线，无需更换矩阵或音频输出接法。每个候选都有自己的gprj和impl文件夹。不要只在旧Designer窗口里重新点Programmer，否则容易继续下载旧工程。

## 下载顺序

1. **先01精度钢琴**，与此前认可的harmonic_piano比较；00共享原版可作声音/资源对照。
2. 再02柔和钢琴、03明亮钢琴、04持续簧管，选择真正想保留的声音。
3. 最后05拨弦细节、06拨弦柔和。这两份默认拨弦；00–04切换到拨弦得到原版，方便回退比较。

在Designer用File → Open Project打开[README表格](README.md)中对应gprj，确认顶层是`palette_`加完整目录名，例如`palette_01_piano_precision`；直接开Programmer前确认它指向当前候选生成的FS。若需在GUI重新生成，运行综合/布局布线，再打开Programmer。仍使用已有SRAM下载模式。

每份的FS位置都遵循同一个规则，例如：

```text
project/audio_palette_lab/variants/01_piano_precision/impl/pnr/01_piano_precision.fs
project/audio_palette_lab/variants/02_piano_soft/impl/pnr/02_piano_soft.fs
```

回退工程为`project/final_dual_timbre/final_dual_timbre.gprj`，旧FS为该工程的`impl/pnr/final_dual_timbre.fs`。新旧构建指纹见[验证记录](VALIDATION.md)；本轮没有替用户下载板卡。

## 按键和旋钮

| 控件 | 本轮行为 |
|---|---|
| 底板S1 / USER_BUTTON2 / Y12 | 候选DDS ↔ 拨弦；仅改变随后新按的音 |
| 底板S2 / USER_BUTTON1 / AB13 | 普通延音开关；拨弦自然衰减，不受它控制 |
| 底板S4 / USER_BUTTON0 / AA13短按后松开 | 旋钮模式依次：音量 → 左区八度 → 右区八度 → 释放长度 → 音量 |
| EC11旋转 | 调当前模式；八度每格12半音，两区互不影响；音量与八度在端点饱和 |
| 底板S4长按约1秒 | 平滑全局止音；全部松开后恢复，不恢复八度/音色设置 |

每次重新下载后从音量模式开始，左区C3、右区C4。模式1/2暂沿用音色灯显示，需要按上述次序切换；释放模式灯闪烁。灯色仍以DDS蓝色/拨弦绿色为基准，不能用颜色区分七份固件。旋钮按压没有接入。

释放模式旋钮往“增加”方向让DDS松键尾音变长，反方向变短；原有默认释放档不变。02/03即使按住/开延音，振幅也会继续自然减弱；延音的作用是暂不加松键阻尼。04是可以保持的持续音。05/06不会因为延音而被强制持续。

## 16键的双区缩略

本轮改成两组各8个白键，便于在现有矩阵上分别摸到一个八度的两端。**不是原来16个连续半音。** 矩阵上的S编号与底板S编号是两套标号。

| 物理行 | 第1列 | 第2列 | 第3列 | 第4列 |
|---|---|---|---|---|
| 第一行，左区 | S1 C3(48) | S2 D3(50) | S3 E3(52) | S4 F3(53) |
| 第二行，左区 | S5 G3(55) | S6 A3(57) | S7 B3(59) | S8 C4(60) |
| 第三行，右区 | S9 C4(60) | S10 D4(62) | S11 E4(64) | S12 F4(65) |
| 第四行，右区 | S13 G4(67) | S14 A4(69) | S15 B4(71) | S16 C5(72) |

两区可各自从C2起到C5起，每组顶端C再高一个八度，所以整体可触达C2–C6。完整24/25键接口是半音排列，不是白键排列；新增实体黑键和完整双八度手感等B的控制板，当前16键不能替代它。

换八度只影响新起音：按住S1，调左区八度，S1不应跳音；松开再按才换到新八度。S8和S9默认同音高但属独立实例，松开其中一个应保留另一个。矩阵无逐键二极管，多键仍可能触发鬼键保护；试听和弦优先使用同一物理行，或任意两键。三个“矩形角”组合会平滑止音，需要全部松开，不是复音计算失败。

## 同条件试听

每份先完全松键、关延音，以相同音量和同一副耳机/音箱比较。先单音S9(C4)，再S1低一个八度、S16高一个八度；再试S9+S10、S9+S11、S9+S13、S9+S16，区分半音/全音附近的拍频与持续尖锐分量。本白键映射没有C#，本轮先用全音对照；黑键输入在逻辑测试覆盖。

请记录：音色是否喜欢；尖锐随音声是否减轻；起音/松键是否有突音；低音复音是否颤抖；切音色是否仅影响新音。正常和声拍频不会仅靠提高数字位数全部消失。

## 电脑参考

每段依次为C4、C3、C5、C大三和弦及释放，约3.15秒。来自**真实八声部RTL的混音输出**，释放步长固定24以压短参考片段；与上板默认释放档不同。未包含模拟DAC/功放/耳机。原电平不归一化，播放设备音量自行调节；matched副本在DDS组（00–04）和拨弦组（05/06）内分别匹配首个C4的RMS，只作衰减；不能拿它推断上板原始响度，也不跨组等响。

文件由`tools/render.py`生成在`sim/audio`；精选副本与可点击链接见[验证记录](VALIDATION.md)。文件名后缀`_matched.wav`表示响度匹配。加速渲染只跳过无事可做的fabric时钟；原版、动态钢琴、两份拨弦均已逐样本对照真实1040拍节奏，初始化阶段保留实际节奏。

目前没有将任何新候选标记为上板音质通过，也没有把本轮数字误差改善等同于公共模拟噪声根因已修复。
