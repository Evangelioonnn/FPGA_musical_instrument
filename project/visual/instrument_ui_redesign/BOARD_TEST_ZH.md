## 两个有效页面

主屏：五音色ID固定0/2/3/4/5，真实状态快照驱动音量、模式、参数HEX、延音、释放、房间效果、声部与H/S/R琴键显示。H为按住，S为松键后gate保持，R为释放尾音。声部占用包含尾音。25键图形为15白＋10黑；实体仍是4×4矩阵的16个自然音，左右各8键，交界Do可能同音高高亮。独立移八度后部分高Do可超出画面窗口，但仍发声。

波形页：上L、下R，512对连续PCM约10.65ms；右侧PEAK显示该窗口双声道绝对值最大原始码，AUTO x2^ n为仅显示用二次幂增益。纵向+V/-V代表当前视图范围，不是模拟伏特或固定数字满幅。自动缩放后高度可能相近，观察音量请看PEAK。绿色小方块表示窗口更新新鲜，不能单凭绿色证明采样值非零；超过约2秒未更新变红。

曲库、编辑、设置等顶部文字为后续入口，本版不能进入；没有FFT、李萨如、蓝牙或Looper。非触控屏。

## 实体操作

| 操作 | 行为 |
|---|---|
| 矩阵16键 | 实时演奏 |
| USER0短按/长按约1s | 切旋钮模式 / 全局止音 |
| USER1短按/长按约1s | 普通延音 / 选择延音 |
| USER2短按松手 | 五音色循环 |
| USER2长按约0.8s | 主屏与波形页切换；持有不重复，松手不切音色；暂替代原长按恢复参数 |
| EC11旋转 | 原音频参数调节；按压未接入 |

Warm pluck保持自然衰减，不能因显示切页而延长。
