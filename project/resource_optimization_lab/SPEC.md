# 资源优化实验规格

## 固定条件

- 器件：GW5AT-LV60PG484AC1/I0（GW5AT-60B）。
- 系统时钟：50 MHz，音频采样使能由已验证的 `pt8211_tx` 产生，约 48076.923 Hz。
- 声部容量：8。
- 默认音色：原 `synth_voice` 的正弦 DDS + ADSR `68/6/32768/3`。
- 输出：PT8211 左右相同样本，保持现有 LSBJ 发送器。
- 所有输入/约束沿用矩阵版 19 IO；本实验不引入额外外设。

## 验收

1. 独立 testbench 检查每个候选在 8 个声部同时活动时持续产生有效样本，且无 deadline miss。
2. 原正弦候选的包络阶段、相位步进、混音饱和和静音尾段必须有明确断言。
3. Gowin 综合/PnR 必须记录 Logic/Register/BSRAM/DSP/IO、setup/hold 和所有未解决警告。
4. 共享候选的调度周期必须远小于 1040 个系统时钟；不能用平均吞吐替代最坏情况证明。
5. 只有同时满足数字等价/可接受误差、PnR 收敛和接口可迁移，才允许进入最终工程评估。

## 资源假设

目前 97 个 DSP 中包含每声部的正弦包络乘法、FM 运算、拨弦运算、最终音量乘法等。显式删掉未选音色只能给出资源下限；真正可迁移的路径是让一个正弦/乘法流水在 1040 周期内服务八个声部，并用寄存器阵列保存每声部状态。
