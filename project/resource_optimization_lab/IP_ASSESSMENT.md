# 官方 IP 评估记录

日期：2026-09-24。工具：Gowin V1.9.12.03.03，器件筛选以 GW5AT-60B 为准。

## 本机可见的 IP

已确认安装目录 `E:/Gowin/Gowin_V1.9.12.03_x64/IDE/ipcore/` 包含：

`DDS`、`DDS_II`、`RAM_pROM`、`RAM_SP`、`RAM_SDPB`、`RAM_DPB`、`DSP_MULT`、`DSP_MULTALU`、`FIFO_SC`、`FFT`、`PLL_ADV` 等。

## 评估结论

| IP | 对本项目的用途 | 本轮动作 | 采用决定 |
|---|---|---|---|
| `RAM_pROM` / `RAM_SDPB` | 正弦表、拨弦延迟线、显示字模 | 对照综合报告确认现有 HDL 已推断 `pROM`/`SDPB` | 暂不替换；先做共享端口架构 |
| `DSP_MULT` / `DSP_MULTALU` | 包络、音量、FM 乘加 | 对照基线确认已有乘法已映射到 97 个 DSP | 暂不封装；封装不会自动跨声部共享 |
| `DDS_II` | 多通道、时分复用 DDS | 读取本机 IP 目录和文档入口，尚未生成参数化实例 | 后续独立 A/B；不能未经仿真替换默认音色 |
| `FIFO_SC` | 输入事件或显示 CDC | 现有 system/矩阵工程已有纯 RTL 队列验证 | 只有跨时钟链路冻结后再采用 |
| `FFT` | C 的 FPGA 频谱显示 | 与音频优化解耦；需要全速采样、窗函数和显示预算 | 不接入本轮音频 |

## 为什么本轮没有直接生成 IP

IP Generator 生成的封装与加密仿真模型需要把参数、初始化、器件版本和仿真库一起交接。当前最紧资源是 DSP，已有 HDL 已经映射到硬核 DSP；在没有一份能保持样本时序的 DDS_II 配置前，直接换 IP 会增加不可控变量，不能称为优化。本轮先验证共享架构，后续可用相同 testbench 作为 DDS_II 的 A/B 入口。
