固件SHA256：`576de89cc54c78fdd88fcf7d92d03a00fba4beeecd508abeabb4e949870c4e83`。
入口 `audio_v2.gprj` / `impl/pnr/audio_v2.fs`。旧variants不是最终固件。
与V1相比，DSP72.5→24.5，BSRAM42→66，声部扩展由状态RAM和共享算子实现。
面积/存储/带宽需要分别比较，不把DSP下降称为所有资源都下降。

首个根入口虽然通过50MHz，但余量仅0.041ns；关键路径为状态RAM到音色幅度DSP。
加入包络计算寄存器后得到上述0.632ns。没有放宽20ns约束或用false path隐藏它。
PR1014通用时钟路由、显式位宽截断与未消费观察端等提示保留；不拿警告数量推断音质。
PRIMARY/LW占用还包含高扇出复位/控制信号，不能解释为八个独立音频时钟；C合并后仍需重新实现。

## 完整接口与输入综合

`tools/audit.py --inputs`保留25键、host/ADC/PCM、2368bit基础快照/扩展/键图，
以及当前矩阵扫描器、EC11、PT8211发送器和指示器：
**28282 Logic / 15135 Register / 53 BSRAM / 24.5 DSP**。
DSP原语为20×MULTALU27X18、2×MULT27X36、1×MULT12X12，按PnR单位折算24.5。
这是仅综合，没有物理引脚分配或PnR；不能拿它的53块代替实际PnR的66块。

A+输入额度剩718 Logic、1865 Reg，按物理PnR剩4 BSRAM、53.5 DSP。
真实SPI和新25键扫描器尚未包含，未来输入Logic空间有限，必要时继续共享或减少拨弦池。
C仍保留13000 Logic/10000 Reg/26 BSRAM/16 DSP/1 PLL。
音频实测+C额度算术合计37052/20684/92/40.5，不是整机PnR或整机时序保证。
Bank5/Y12、显示像素域CDC、蓝牙与真实ADC仍为整合门槛。

## 数值与声音边界

固定权重：谐波Q4原样本权重1，拨弦权重4，累加后对称舍入除64。
这意味着谐波每音固定为V1的1/4（-12.04dB），拨弦电平不变；不按活跃数归一化。
`headroom.py`独立保守上界：32谐波23552码；12拨弦+20谐波最大27008码，距32767剩5759。
CH0最大Q16=65536，四谐波Q8默认[256,64,32,16]，总和限368、全满[92,92,92,92]。
共享反馈房间为有界凸混合，不用主音量静音掩盖削波。不同音高听感/谐波突兀仍需用户试听。

每个声部有独立相位、音高/滑入和包络；其四谐波共相位/包络，32声部不能计成128独立振荡器。
本轮32个不同音高的相位递推已独立检查；旧独立钢琴的32不同谱峰证据仍属于那个实验，不能冒充已测V2模拟频谱。
物理16键无二极管矩阵不能任意按32键，32容量需顺次延音或逻辑注入验证。
