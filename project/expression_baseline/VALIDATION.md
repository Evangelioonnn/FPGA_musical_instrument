# 本轮修订与验收规格

2026-09-18：用户反馈统一基准演示效果很差，要求直接修改本工程，所有功能试听使用原 instrument 的“类似钢琴”声音。

## 目标

- 八个声部直接复用原 `synth_voice`，原正弦ROM、ADSR=68/6/32768/3 不变。
- 力度256、总增益65536时，单声部样本与原声音逐样本一致（允许已说明的流水线延迟）；力度64/128为原样本的1/4、1/2，负数采用向下取整。
- 混音不按最大声部数除以8。采用16+ceil(log2(N))位有符号和、完整Q16增益乘积，最后饱和为16位；单声部峰值约512码，八声部理论绝对峰值不超过4096码。
- 各声部采样使能、样本有效标志一致；传输继续复用PT8211 LSBJ。原 instrument、expression 音频源和引脚约束不因本轮调整而改变。
- 选择性延音的新音持键至少0.3秒；逐音增加的四声部最后一个音持键至少0.25秒；八声部用分布于不同八度的C大三和弦，避免用C-D-E-F-G-A-B-C音簇作为基准音色展示。

## 验证分层

1. 原 `synth_voice` 独立实例对比：原包络完整运行，验证正负样本、力度、释放静音。
2. 混音边界：正负最大输入、静音、相消、音量变化和饱和标志。
3. 顶层短时串行回归：保持真实50MHz/1040采样间隔，仅压缩事件间隔；逐位核对左右声道，统计声部数量而非位掩码，确保完整收齐音符按下/松开。
4. 完整16秒渲染：保留全部真实音频样本和包络时长，只减少相邻采样间闲置的系统时钟；检查音量、踏板、八声部、样本求和、最终释放，输出参考WAV。
5. Gowin综合/PnR/时序及最终文件指纹。板卡听感仍须用户确认。

## 尚不能认定的原因

此前的26位赋值本身提供Verilog表达式位宽上下文，不能仅凭乘法写法认定发生截断；本轮显式扩展仅用于明确计算。原低幅度样本下16位求和也不会溢出，扩大混音位宽是边界保护，不是已证实的杂音修复。原模拟尖锐声、底噪仍待板测/示波器核查。
