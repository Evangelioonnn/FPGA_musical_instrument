# 音频核心规格 V1

接口位宽、时序和快照见[共享接口](../../docs/interfaces/AUDIO_CORE_V1.md)。
所有音频逻辑在50MHz域运行，`sample_ce`每1040时钟一次，实际
Fs为48076.9230769 Hz。按键适配、音频计算、房间效果及输出增益均不得阻塞这个节拍。

## 音色与声部

新菜单保留ID `0/2/3/4/5`，不重编号。八声部各有32bit击键token；
DDS类各有独立相位、频率和包络，Warm pluck各有独立延迟线和衰减状态。
同音不同token可叠加。满载拒绝新音，保护旧音和尾音；不偷音，也不按活跃声部数改变增益。
松键按token匹配，改变八度或音色后仍释放原实例。菜单只改变新击键的音色。

| ID | 音色 | 适用控制 |
|---:|---|---|
| 0 | Precision harmonic piano | 普通/选择性延音，释放，平滑弯音，ADSR覆盖 |
| 2 | Warm pluck | 一次击键自然衰减；忽略踏板与ADSR覆盖，不强迫持音/可调尾音 |
| 3 | Metallic bell | 自然明亮衰减、松键释放；忽略踏板和弯音 |
| 4 | Drive lead | 持音、两种延音、释放、滑入、弯音、颤音、ADSR覆盖 |
| 5 | 自定义四谐波 | 持续音实时改系数、两种延音、释放、弯音；新击键可选择持续包络 |

默认沿用认可的无音区补偿渲染路径，`PROFILE=6 / BALANCE_MODE=0 / TONE_SHIFT=0`。
9000帧比较覆盖新旧声部输出和状态，精确相等；这个结论位于主音量和效果器之前。
主音量改为单一权威参数目标，默认Q16=8249，等于旧custom引擎的
`floor(8250*65535/65536)` combined_volume_target。旧实现先组合两个控制系数，
也只有一次knob_gain施加于PCM；本轮9000帧逐位证据仅覆盖bank，未作新旧末级PCM逐位比较。
复用的 `knob_gain` 每帧最多移动128个Q16码，0到满量程约10.65ms。
启动实际增益仍从65536平滑到默认8249，参考音先留550帧静音稳定；不是ADC推子从默认位置自动接管。

## 包络、滑音与调制

默认钢琴ADSR码为 `68/6/32768/3`，Lead默认起音索引2、衰减2、保持56000。
单位是每PCM帧增加/减少的16bit幅度码，不是毫秒。A/D/S在击键时快照；
覆盖开关及custom_hold同样只作用于新击键。R在真正开始释放时读取，已进入释放的实例保持原R。
旋钮释放索引0..7对应96/48/24/12/6/3/2/1；Lead默认R再乘8，Warm pluck不使用这套尾音控制。

Lead的滑音索引0关闭，1..4为1024/2048/4096/8192帧，约21.30/42.60/85.20/170.39ms。
新Lead声部从最近仍按住的Lead声部频率滑向自身音高，并创建新的包络和相位状态；
这是复音滑入，不是不重触发包络的单声部legato。
弯音索引-8..8每格四分之一个半音，范围±2半音；平滑改变频率系数，不重置相位。
颤音只送入Lead，深度0默认关闭、最大约±55音分，速度索引0..7约2..9Hz。
颤音是主动音乐调制，与历史不希望出现的颤动杂音分别验收。

## 四谐波与ADC

`CH0`是所有音色混音及房间效果之后的主音量。
`CH1..4`分别控制基频、2/3/4倍频的幅度，raw ADC均0..4095；实体芯片/SPI/J13尚未接入。
主音量Q16使用0..65536，0静音、65536单位增益；不要套用旧custom模块65535满量程的文档。
四谐波用9bit Q8，256为1.0，默认 `[256,64,32,16]`，raw默认 `[4095,1024,512,256]`。
每帧平滑步长≤2，各声部渲染开始时读取同一完整系数组。

有效系数和≤368；超过时按比例向下归一化。四根全满得到 `[92,92,92,92]`。
变化过程中先下降、再在剩余额度内上升，保持和≤368。
单声部Q4绝对值保守上界47102，八声部混音转16bit后的绝对值上界23551；
因此全推满、八声部同音及主音量=65536仍有数字幅度余量。
归一化可能在总幅度超限时降低其他谐波；这项规则是已公开的固定幅度约束。
四阶谐波共用每声部相位/包络，不能记为32个独立振荡器。

主机和实体推子之间采用pickup接管，避免远程改值后推子位置瞬间跳回。
CH0物理零点无条件静音；其余接管、ADC整帧拒收和系数背压见
[参数服务规格](../audio_parameter_lab/SPEC.md)。

## 效果、输出与故障

短房间效果在主音量之前，4条601/733/887/1091帧反馈环共享4096×16 RAM。
wet参数为Q8，0..128即0..50%，默认目标32、效果开关默认关。
启停平滑，每有效样本最多变化1码；旁路完成后左右逐位等于干声。
湿声左右权重不同，可为C提供真实立体声观测；关闭效果时L/R仍相同。
效果输出延迟24时钟，完整音频的最终PCM在每个1040周期内完成。

panic或矩阵鬼键/队列溢出使主音量平滑到零，然后清声部及效果RAM。
按键全部松开后恢复，效果旧尾音不会在恢复后重新冒出。
清理可中断一次本应为零的PCM更新；PT8211保持零样本，PCM序号可看到间隔，见接口说明。
clip与deadline都是可观测诊断，不以持续限幅掩盖满载异常。
参数恢复默认只重设目标及pickup，不自动清掉已有声部；要清声部用panic。

物理输出复用既有PT8211 LSBJ/右对齐发送器，不改为不兼容的Philips I2S。
现有CST/SDC沿用已测试的19针音频/矩阵/EC11布局；没有HDMI输出。
