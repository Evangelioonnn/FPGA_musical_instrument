# 上板验收 · 音频核心 V1

本固件是这轮首个待试听整合候选。既有音色获认可不等于本固件全部板测通过。
沿用目前已接好的矩阵、EC11和耳机/扬声器线路，**不需要新增器件或移动接线**。
细针表见[既有接线记录](../input/matrix_playable/WIRING.md)，该文档旧音符布局不适用于本版。

## 操作

下面的S1/S2/S4均指**底板**用户键，不是矩阵按键。

| 底板操作 | 动作 |
|---|---|
| S1短按后松开 | 钢琴0→Warm pluck2→铃音3→Drive lead4→自定义5→钢琴0 |
| S1长按约1秒 | 参数恢复默认、旋钮回音量；未自动清声部 |
| S2短按后松开 | 普通延音开/关 |
| S2长按约1秒 | 选择性延音开/关；松开不额外切普通延音 |
| S4短按后松开 | 切旋钮模式 |
| S4长按约1秒 | 平滑止音，清全部声部和效果；松开全部矩阵键后恢复 |
| EC11左右旋转 | 减少/增加当前模式参数；未使用旋钮按压 |

切音色后模式回0。旧声部保留旧音色，先全部松键或止音再比较新音色。
状态RGB沿用旧指示器，只编码模式低3位，17种模式不能逐项唯一辨色；请按下表计数。

非自定义音色的S4循环模式：

| 次数/模式 | 旋钮控制 | 初值及每格变化 |
|---:|---|---|
| 0 | 主音量 | 18档，0..24；0完全静音 |
| 1 | 左区八度 | MIDI48，±12，36..72 |
| 2 | 右区八度 | MIDI60，±12，36..72 |
| 3 | 释放长度 | 索引5，0..7；向右更长，拨弦不适用 |
| 4 | Lead滑音 | 0关，1..4更长；在旧Lead按住时再弹新音 |
| 5 | 弯音 | 0，±0.25半音，±2半音；离开此模式回中 |
| 6 | Lead起音 | 索引2，0..3；向右起音更快，作用于新音 |
| 7 | Lead颤音深度 | 0关，每格4，最大64 |
| 8 | Lead颤音速度 | 0约2Hz，0..7约2..9Hz |
| 9 | 房间效果开关 | 左关、右开 |
| 10 | 房间湿声比例 | 32/256=12.5%，每格8，0..50% |
| 11 | ADSR A | 68码/帧，每格32；调整自动开覆盖，新击键生效 |
| 12 | ADSR D | 6码/帧，每格2；更大衰减更快 |
| 13 | ADSR S | 32768，每格4096；0..65535 |
| 14 | ADSR R | 3码/帧，每格2；更大释放更快 |
| 15 | ADSR覆盖开关 | 左关、右开；新击键生效 |
| 16 | 自定义持音包络 | 左关、右开，需先设定后切到ID5并新击键 |

自定义ID5的模式为0主音量、1基频、2二倍频、3三倍频、4四倍频；每格raw ADC±64。
四谐波在长按音符时实时改变。此处是旋钮模拟推子，不表示实体ADC已连接。

## 建议验收顺序

1. 先只查五音色顺序、单音/双音/尾音，比较此前认可版本和参考WAV。不要一开始开启所有效果。
2. 试静音、最大音量、快速连弹及低音和弦；记录是否出现新增起音声、削波或此前尖锐伴音变化。
3. 钢琴验证两种延音：选择性只捕获开启当时仍按住的音；之后新弹的音不被它锁住。两类同时打开，再逐个关闭。
4. 长按S1恢复默认；Lead再验证滑入、弯音和颤音。滑入不是单声部legato，不要求旧音自动被新音替换。
5. 先开房间效果，再调湿声到64=25%；试听立体声尾音。静音必须同时消除原音和效果尾音，止音后恢复不能冒出旧尾音。
6. 检查ADSR改变新音的起音、衰减、保持和释放；Warm pluck不强制套用这些控制。
7. 切ID5长按音符，逐谐波扫动，试四路最高/最低；检查没有突跳、异常削波或断音。
8. 16/32钢琴另用[独立验收指南](../audio_polyphony_lab/BOARD_TEST.md)，其按键动作与本工程不同。

记录.fs指纹、供电、监听设备、音色ID、音符、音量、控制动作和异常时刻。
物理ADC、25键PCB、HDMI/蓝牙整合与输入到模拟端延迟不在本次已通过范围。
