# Looper候选功能与数值契约

2026-10-07；数字证据见[VALIDATION](VALIDATION.md)，板测待用户验收。

## 时钟和全局节拍器

50MHz；Fs=50,000,000/1040=48,076.9230769Hz；96 PPQN。BPM 40～240钳位、默认120、每格1 BPM；2/4、3/4、4/4，分母固定四分音符。控制器只允许Looper停止时改拍号/循环长度，循环长度1～4小节。

累加器每帧加 `BPM×96×1040`，阈值3,000,000,000，越界保留余数。不用整数除法截断每拍长度。恒定BPM时第k拍为 `ceil(k×3e9/(BPM×1040))` 个音频样本，算法误差不超过一帧（20.8µs），不累积舍入漂移。实物还受50MHz晶振误差影响，本轮未测晶振ppm。

启动立即第一重拍；静止时关节拍器，时钟停止；Looper运行时关点击只关闭声音，循环相位继续。Looper启动重对齐，包含一完整小节预备拍，预备拍强制有声。BPM在下一拍边界生效；拍号在停止/重启或小节边界应用。

点击独立相位/包络，480样本约9.98ms，强/弱拍约2kHz/1.5kHz，不占旋律或鼓槽，不录音、不进房间效果/延音。增益无符号Q8 0～256、默认96，1 LSB/样本平滑；仍受主音量/全局静音控制。

## 轨、层和生命周期

四循环轨＋独立现场来源。每轨4层，每层128事件，共2048；一次按下/松开通常占2事件，鼓击打占1。满层不覆盖旧层；事件/活动实例溢出取消整次take并置故障。新take使用选中轨首个空层；撤销清除最后有效层，清空只影响选中轨。取消当前take不影响已提交层。

停止/撤销/清空给相应循环旋律发松键，给相应鼓尾音短释放，不对现场持续音发全局panic。停止后允许自然尾音，不是立即归零。录音未松实例在最终tick补松键。末拍事件及缓冲先排空，再补松键/提交，避免回绕盖掉时间戳。

时间戳在现场路由捕获时锁存，不随bank延迟或播放回绕改变。量化只影响记录/回放，不延迟现场。关闭/48/24/12 tick四档；四舍五入至最近网格，末端钳位 `loop_length-1`。同tick优先松键再开音；阻塞事件整包保持到握手消费。

回放 `(track,layer,local_id)` 映射唯一32bit运行token，同音高不合并。bank接受后才建立有效映射，拒收不留幽灵held。鼓满载消费并报告拒绝，不录入未接受的现场击打。循环满载拒收会影响音乐结果，需要用户避免超过容量；不偷音。

## 音色和冻结参数

ID固定：0钢琴、2 Warm pluck、3铃音、4 Drive lead、5自定义、6鼓组。每层一个patch，**在实际record_start而非按录音键/预备拍开始时捕获**。下一层可以换音色，四轨可同时含多种乐器。录音中改现场音色/系数会改监听，但当前层回放仍用开始patch；换音色建议新层。

四谐波无符号Q8 0～256，256=1，默认 `[256,64,32,16]`。旋钮模拟0～4095原始推子，经既有服务映射、平滑到应用Q8值；捕获应用值而非未收敛目标。循环不受后续现场系数/ADSR/踏板影响。循环Lead冻结glide/attack，滑入源限同轨；连续弯音/颤音/踏板序列不录入，循环播放实时pitch factor固定unity。

## 复音、混音和上界

旋律32共享槽（含尾音），Warm pluck物理12计入32；鼓8独立槽。现场和所有层共同争用容量，四谐波不乘四申报振荡器。循环轨音量Q16 0～65536=0～1，静音/调节每样本变化≤128；现场不乘轨音量。主音量后置Q16≤unity，无活跃声部数归一化。

路径：各旋律轨增益→旋律混合/饱和保护→可旁路短房间→加鼓/点击→固定1/2总线裕量→平滑主音量→PT8211。鼓和/16，鼓与点击不进房间。

保守界：旋律限幅≤32768；8鼓各≤32768，和/16≤16384；点击≤7680；aux≤24064，总线/2≤28416。主音量≤unity，最终加法不再溢出。固定1/2令单旋律相对原V2低6dB，可提高主音量补偿，不能称电平不变。

在V2固定每音1/4基础上，自定义默认系数总和368，32同音保守界≤23552。四根全满总和1024，单音≤2048、8声部≤16384；**32声部保守界65536超出旋律bank范围**，极端组合可能先在bank限幅，保留clip记录。不能声称任意32×全满均无削波。

## 鼓垫顺序

key0～15：底鼓、军鼓、低筒鼓、中筒鼓、高筒鼓、闭镲、开镲、吊镲1、吊镲2、Ride叮叮镲、Ride bell、脚镲、拍手、边击、牛铃、沙锤。底鼓/筒鼓下降音高正弦，军鼓正弦＋噪声，镲片噪声＋金属方波，独立衰减。闭/脚镲立即截断开放镲，目前choke未做短fade听感验收。不播放样本，不宣称复现Mutable Instruments音色。
