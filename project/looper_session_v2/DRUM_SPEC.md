# 鼓组修订 · 2026-10-10

依据10月9日实物听感调整，旋律部分保持原样。音色菜单6下映射如下；key是实际扫描的行×4+列编号，不保证等于键盘外壳印字。

|---:|---|---|
| 0 | 底鼓 | 原低筒鼓的主体、起音与滑落保持逐样本一致 |
| 1 | 军鼓 | 音色、包络、相对电平逐样本不变 |
| 2 | 四筒（最低） | 原筒鼓公式，落定 D2≈73.416 Hz |

有效 mask 为 `16'h33ff`。实际开/闭踩镲含义按用户定义：未踩时敲击=开，踩住时敲击=闭；这里只用pad代替两类敲击，本版没有实体踏板。

参考[tune-bot 调音指南](https://tune-bot.com/tuning-guide/)的四筒 Call to Post 方案（16/14/12/10英寸，约73.4/98/124/147Hz）。采用的是基频，非鼓皮边缘张力的测量频率；它是常见可选调音，不宣称所有真实鼓组通用标准。这里用十二平均律 D2/G2/B2/D3，起音频率2倍后滑落至基频；原公式、攻击和衰减类型保留，筒鼓电平增为9/8。两吊镲的衰减移位为13/14，开镲11、闭镲9。

计算使用共享正弦表和分时乘法。单槽绝对上界保守36864，8槽前混音≤294912，经 `>>>4` 后≤18432；最大点击≤7680，辅助和≤26112，16bit有符号辅助累加不溢出。旋律与辅助仍走既有混音裕量、主音量与末端保护；这些界不能证明真实DAC/功放没有杂音。

闭踩镲choke开放镲：有空槽时保留旧开放镲并短淡出，新闭镲占空槽；8槽全满时只允许对开放镲的明确choke替换，仍可能有切换突变。这是继承的满池限制，不能称完全无点击；其他满池新击打拒收、不任意偷鼓声部。实际试听先验空槽下开→闭，再决定是否值得专门改善满池choke。

本轮电脑参考 `drum_kit.wav` 顺序为 **0、1、2、3、4、9、5、6、7、8、12、13**，不同pad共用一个固定试听增益6倍；鼓的相对电平未分别归一化。吊镲各约1秒，其余各约0.5秒。WAV来自RTL，不放回FPGA播放。
