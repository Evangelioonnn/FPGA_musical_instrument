# 正弦杂音 A/B 排查规格

用户实测 M1：左右均衡、主观音准正常、尾音自然；小底噪持续存在，尖锐附加声与音符同时出现/消失并随音高变化。未提供录音/频谱，不能确定模拟或数字根因。原 instrument 保留为 A 参考。

已分析原 RTL 保持段，去除最佳拟合正弦和 DC 后残差约 -52.45 dBc；2～20 kHz 最大谱线随音符不同约 -60.25～-66.98 dBc。此为数字仿真，不是板卡噪声实测，也不能证明对应用户听到的尖锐声。

## 对照只改变波形数值精度

- A：原 1024 点查表、直接截断到试听音量。
- B：同一 1024 点表的相邻两点，用额外 8 位相位小数线性插值；最终增益转换采用四舍五入。保持原采样率、音高、ADSR、输出格式、引脚和名义幅度。
- B 新样本在 sample_ce 后第 5 个系统周期有效；下一 sample_ce 必须至少间隔 6 个周期，实际间隔1040周期。插值与包络计算均在 FPGA 内进行。
- B 舍入后峰值范围 -512..512；A 为 -512..511，两者没有名义增益差。不能承诺 B 消除模拟链路失真/底噪。
- 顶层使用两条并行计算通路，仅选择一条送 DAC，不相加。前6秒选 A、后6秒选 B，12秒循环；每6秒均为静音1秒、C4/E4/G4/C5四音、静音1秒。模式只在零输出边界切换。
- PA_EN 仍保持低电平，不通过开关功放掩盖问题。

## 验证

1. 生成相同事件驱动的 A/B 样本，核对精确正弦误差、释放归零、复位和输出幅度；核对 B 新流水线有效时刻。
2. 用相同频率拟合、残差和频谱方法比较 A/B，不能只看频率。
3. 实际50MHz串行链路验证缩短事件槽的完整A/B循环，包括模式切换静音、声道和帧检查。
4. 综合/PnR/50MHz内部时序通过后供用户对比。没有耳机反馈前不称为已修复。
