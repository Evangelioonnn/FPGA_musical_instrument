# 尖锐附加声：A/B 无改善后的分析

日期：2026-09-18。状态：根因未确定。用户确认参考 WAV 干净、板卡仍尖锐；计算精度 A/B 和 `../audio_format` 串行格式 A/B 均无可闻改善。当前优先排查实际数字引脚及 DAC/滤波/功放/耳机负载环节，不再无依据增加软件 A/B。原 instrument/audio_quality RTL 和下载文件未修改。

## 2026-09-20：旋钮交互新增异常

见[旋钮板测记录](../../evidence/knob_suite_2026-09-20/BOARD_LISTENING.md)。音量和释放控制获认可，逐格基础弹奏有效；快转新音起音有大噪声，音色版只有转动切换时有主观延后的附加声，保持默认音色不转时无此新增声。本轮电脑参考没有这些异常；不演奏时有可闻底噪。FM主观最差、拨弦最佳，与此前排序一致。

新增现象需要核对真实旋钮事件/启动时序及板上电气，不能只沿用“固定音色失真”的解释。已复核默认音色参考前96000样本及逐格参考384616样本数学精确一致，数字静音尾段为0；未测实际串行码与模拟输出。用户进一步做了volume减至0后继续朝减小方向快转，确认静音时没有突发杂音。这降低了纯旋钮动作耦合的优先级，但0音量端点的配置/有声运算状态与实际演奏不同，不能排除全部电气问题，更不能直接证明硬件损坏。

## 2026-09-19：FM／pluck新板测反馈

用户确认三种音色主体均能对上对应WAV，但都有程度不同的随音高变化附加声；pluck很轻、接近可接受，FM很大。详细条件及原话见[板测记录](../../evidence/timbre_rtl_2026-09-19/BOARD_LISTENING.md)。这增加了检查公共链路的价值，不等于确定是同一个失真源或板卡损坏。

已发现一个必须补齐的数字对照条件：FM/pluck核心WAV之后，板级probe还做算术右移5位。相同样本经此变换，FM峰值116码、pluck221码；固定监听增益很低，且引入额外整数截断。补充[FM参考](../../evidence/audio/fm_monitor_preview.wav)和[pluck参考](../../evidence/audio/pluck_monitor_preview.wav)先保留这一步量化，再统一×32便于电脑试听。不是板卡录音或真实引脚全帧捕获；不改现有固件。

**用户已确认“两个补充材料声音都很纯净”。** 因此降低除32整数截断本身是主要可闻原因的优先级，下一步查实际输出/转换/模拟链路。这不排除低数字幅度下PT8211的非线性，因为电脑试听经过另一套DAC和模拟增益；也不能证明板上BCK/WS/DIN和采样正确。pluck的瞬态和频谱可能改变掩蔽程度，不能由听感差异直接断言其硬件失真更小；未把推力不足、DAC低电平失真或量化中的任何一项定为根因。

## 共同因素复核

1. **公共串行输出和实际实现。** RTL 接收检查器验证按所建协议模型工作，并非真实 DAC 的模型，也没有验证综合后实际引脚波形。PT8211 V1.6 第4页对超过16位时的文字/图示存在解释空间，为此已完成20时钟（4零+16数据）和恰好16数据时钟的等采样率对照，用户反馈无区别。接下来应测量真实 BCK/WS/DIN 并解码与参考样本比较，不能继续凭手册表述推断这就是根因。
2. **很低的数字幅度是 A/B 的共同条件。** 16 位有符号输出满幅约 ±32767，现有包络峰值约 ±512（-36.1 dBFS），保持段约 ±256（-42.1 dBFS）。接口仍是 16 位，但保持段只使用约 513 个相邻码，输出量化与 DAC 低电平非线性值得检查。B 的数字总残差仍约 -56 dBc；不是“已经消除了全部数字失真”。原低增益出于初次耳机试听考虑，应作为最终增益设计中的限制记录。
3. **DAC 和模拟环节会产生代码中不存在的谐波。** 已复核 NEO Dock 官方原理图第 10/21 页：PT8211（3V3A）→ LMV321 二阶低通 → NS4263 → 隔直电容 → 耳机口。低通与输出隔直均已存在，不应在无证据时假设缺失。PT8211 手册第 5 页在 5 V/1 kHz 条件下列出 -10 dBFS 时 THD 典型 0.1%、-60 dBFS 时典型 3%；这只支持“低电平表现需考虑”，不能插值得出本板 3.3 V/-42 dBFS 的失真值，更不能认定芯片损坏。
4. **耳机与听觉比较。** 同一耳机可控制一项变量，但电脑与板卡的 DAC、驱动能力、模拟增益不同；对比应尽量接近主观响度。听感结果用于缩小范围，不代替频谱/波形。

## 当前排查顺序

**硬件相关因素优先级上升，但“硬件原因”不等于“板卡损坏”。** DAC低电平转换特性、模拟驱动与耳机负载、耦合或接触状态均可能相关；现有低数字增益也属于软硬件工作点选择。仅凭听感无法在这些原因中定位。

1. **两副耳机对照已完成，均有同样问题。** 降低单副耳机异常的优先级，但两副耳机都属于耳机负载，不能排除功放驱动或接触/检测的共同因素，不再重复要求这一测试。
2. 有逻辑分析仪时，采集真实BCK/WS/DIN，按LSBJ而非默认Philips I2S解码，确认采样率、字长、符号和波形样本。仅RTL仿真/内部STA不能替代此项。
3. 有示波器且能可靠接触测试点时，依据底板原理图沿 PT8211输出 → LMV321滤波输出 → 耳机输出逐级观察，记录第一处明显失真及相应频谱。PT8211输出含直流偏置，测量需要合适的耦合/量程；具体探点、接地和操作等设备/探头条件确认后再给，不让初次接线的用户直接试探密集引脚。
4. 仅有手机时，可先录制耳机实际发声作为线索；手机麦克风、自动增益和降噪会改变频谱，不能代替电气失真测量。直接接电脑/声卡采集前必须确认其输入种类和允许电平，普通麦克风口不能默认当作线路输入。

用户已确认两通道示波器、×1/×10探头可用，下一步进行模拟波形定位；逻辑分析仪可用情况未知。当前不要求购入新DAC、功放或更换板卡。

## 两通道示波器：待实物测点确认的方案

本方案依据官方 NEO Dock 原理图第10/21页。用户要求直接给出芯片脚号，当前第一轮明确为 **CH1=PT8211-S第6脚，CH2=NS4263第5脚**，均测左声道；CH2在耳机隔直电容之前，用来比较DAC与功放输出。通过芯片顶标及1脚标记识别器件，不能凭PCB朝向猜脚号；尚未通过实物照片确认元件方向。

| 节点 | 原理图连接依据 | 作用 |
|---|---|---|
| P1：左 DAC 输出 `HP_LCH` | U16/PT8211 第6脚，R123靠DAC的那一端 | 检查数字转换后是否已经有明显失真/尖峰 |
| P2：左滤波输出 `HP_LCHU` | U17/LMV321 第4脚，C111靠滤波器的那一端 | 区分DAC与滤波级问题 |
| P3a：左功放输出 `VOLN` | U20/NS4263 第5脚，C135隔直电容之前 | 当前CH2首选，便于按16脚芯片编号定位；必须保留耳机插入状态 |
| P3：左耳机输出 `HP_OUTL` | C135隔直电容靠耳机的一端，同时连接R137非接地端和J25左声道 | 检查最终带耳机负载的模拟波形 |

优先使用能稳定接触的元件焊盘，不能仅按原理图纸面左右判断PCB元件两端，更不能根据IBOM焊盘数组顺序推断脚号。U16第6脚等编号来自原理图/芯片手册，但实物芯片方向仍需标记确认。

已读取 `Notification/Mega60K_官方资料/PCB_BOM/ibom_Tang_Mega_NEO_Dock_31004.html`：元数据日期为2024-09-23；当前原理图为2025-03-31 Rev1.4，资料版本不能视为已经与实物完全对应。该BOM显示U16/U17/U20/R123/C111位于背面，C135/R137和耳机座位于正面，仅用于找元件区域，尚未验证具体网络到焊盘的映射。

第一轮采用现有固件，保持耳机插着、保持原供电，**不要为测波形拔掉耳机**：图纸说明插拔耳机会改变NS4263工作模式。先CH1=P1、CH2=P3a；若两者差异明显，再用P2细分；C135后的P3可进一步检查隔直电容/耳机接口。只有测点和接地可可靠固定时才上电；不要求带电翻板找背面焊盘。

芯片从有字的一面看，按1脚标记逆时针编号：把1脚放左上时，PT8211-S的6脚在右排自上第3个，NS4263的5脚在左排自上第5个。PT8211-S第4脚是GNDA，但地夹宜接同网且已确认的GND大焊盘/排针，不用宽地夹夹密集芯片脚。NS4263第5脚名称中的N不表示地，地夹不得接此输出。

台式示波器两通道地夹通常共地并接保护地，只接已经确认的板卡GND/GNDA；扬声器正负输出均不能当作地。图纸GND/GNDA通过R213（0Ω）相连；仍需选择实物明确的接地点。使用高阻输入（通常1MΩ），不用50Ω终端；探头物理档位和通道衰减设置一致。

初始可用×10，先确认直流偏置和幅度，再用AC耦合观察小交流波形，水平约1ms/div，垂直调到波形约2～6格。原数字增益很低；若×10受最低量程限制看不清，可评估改×1观察低频音频，但其负载更大，需记录并与×10交叉确认。常规采样下若有足够存储，尽量保留≥1MSa/s；先不启用平均或高分辨率处理以免掩盖短尖峰。具体菜单取决于示波器型号。

四音仍会自动轮换；在某个音的保持段按RUN/STOP捕获，记录是哪一个音、两个通道的Vpp、耦合/探头档位/时基/采样率。先找削顶、零点附近跳变、周期性尖峰及高频振荡；PT8211原始输出本就有采样保持台阶，不能把所有台阶都认定为异常。外观像正弦仍可能有可闻低幅谐波，必要时再用FFT/导出采样比较，不能据屏幕形状直接宣判正常。

如果后续做数字电平扫描，应分档并控制耳机响度；直接放大不是本次结论，也不能仅凭“听起来相对干净”区分量化、DAC 非线性和听觉掩蔽。暂不盲目加入低通、降噪或直流偏置掩盖问题。
