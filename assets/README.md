# 显示、曲谱和数学表素材

存储小而必要的源素材、转换脚本、ROM格式说明和权利来源；目前没有选定图片方案。MATLAB把琴键/五线谱转RGB是一个候选，程序绘制或字模/图块也可用。

每份素材记录原始来源、许可、尺寸/位深/调色板、地址顺序、颜色通道顺序、生成命令和输出大小。ROM应可从提交的输入再生成；小型必需初始化文件可提交，不能被宽泛gitignore误排除。

图片内存预算见[DISPLAY](../docs/board/DISPLAY.md)。不要用没有授权的商业曲谱/图片；不把预录乐器整段PCM当作可提交的“合成波表”。测试WAV放[evidence](../evidence/README.md)，仅供听感参考。
