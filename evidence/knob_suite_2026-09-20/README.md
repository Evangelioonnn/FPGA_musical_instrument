# 旋钮控制候选证据 · 2026-09-20

本包对应分支 `codex/knob-performance-suite`，基线提交 `7a9ac41`。它记录五份待上板的 EC11 固件、数字验证和 Gowin 实现结果；**不包含真实板卡录音，也不表示旋钮新固件已经板测通过**。实际下载顺序和反馈表见[早上验收指南](../../docs/project/KNOB_REVIEW_2026-09-20.md)。

## 验证结果

- 11 个 ModelSim bench 通过：原音色回归、16 声部分配、五模式控制、增益/回声、生命周期取消、8 声部混合音色、50 MHz/1040 传输、完整渲染、滑音/弯音和普通/选择性延音。
- 五种渲染各 384,616 个采样；逐格演奏额外通过独立数学模型逐样本核对。20 次触发中最多 9 个可闻声部同时存在，输出与独立 DDS＋ADSR 求和完全一致，没有按活跃声部衰减。
- 五个最终顶层均为 7 IO，50 MHz setup/hold 无违例：performance 9330 Logic/17 DSP、volume 5398/17、timbre 17765/97、release 4735/17、echo 4821/19。三音色版仍是资源最紧的候选。
- 加速渲染与完整池配置输出逐字节一致；跳过采样之间的空闲时钟，并将固定谱例中未用到的volume/release/echo声部池缩为4/2/2，performance保持16、timbre保持8，不改变采样事件、包络或音频数据。拨弦初始化帧仍保留1040周期。

`validation.json` 保存构建资源、时序、源码指纹与 bench PASS 行；`audio_analysis.json` 保存 14 个来自 RTL 的原始/固定×8预览 WAV 和频率、尾音、音量、回声检查；`performance_oracle.json` 保存独立复音期望；`render_equivalence.json` 保存两种渲染的字节比较。

## 证据边界

EC11 接线沿用实物已测的 3.3 V、GND、A→T18、B→R17，C 悬空；PMOD-LEDx8 应拔下。按压触点尚未确认，普通踏板和选择性踏板只有逻辑验证。五份固件仍使用原 PT8211 音频约束，耳机上的随音高变化尖锐声仍需实验室测量，不能由电脑 WAV 或 PnR 结果排除。

短串行测试未运行到下一次0.5秒自动音色事件，其串行声源为默认音色；FM/pluck切换由multi/render及此前单音色验证覆盖。内部采样计算截止通过也不等于比赛要求的实物控制到模拟发声延迟已测。音量最低若干档受既有低监测电平的量化限制；普通/选择性延音和滑音/弯音没有绑定实体操作。

`initial_timbre_placement/` 保留三音色第一次布局失败的边界记录；通过移位加法等价优化后，DSP 从 105 降为 97，最终 PnR 通过。构建日志中的 PR1014 和位宽截断警告已保留，需在最终整机版继续评估。
