- `build_provenance.json`及Gowin报告：最终19 IO、八声部三音色、50MHz通过；0.251ns setup、0.048ns hold余量；保留工具警告。

- `audio_analysis.json`：完整原默认音色数学逐样本核对、PCM峰值/均方根/指纹。末100ms应为数字零。
- 三份`matrix_*_preview.wav`：每份约16秒、双声道相同、固定×8试听增益；不各自归一化，不是板卡模拟录音。原始板级电平WAV可由脚本重建，保留本机`sim/audio`，不重复提交。
- `initial_timing/`、`event_pipeline_timing/`：两个明确失败的时序阶段；不得使用其过期源码指纹或比特流代替最终通过版本。

本机.fs不进入Git；构建脚本验证新文件时间及完整依赖指纹，证据收集脚本会拒绝源文件变化后的旧构建。提交号用本任务分支的Git记录定位，SHA256用于关联实际下载文件，不能拿旧工程同名.fs代替。

## 三份参考音怎样听

同一套动作分别驱动原默认、拨弦、FM：

| 时间 | 输入与目的 |
|---|---|
| 0.05–约1.2s | C4，0.70s松键；默认尾音 |
| 1.50s | E4，2.15s短释放；拨弦仍走自己的自然衰减 |
| 3.00s | G4，3.65s长释放；比较适用音色的尾音长度 |
| 4.30/4.40/4.50s | 依次C4/E4/G4；4.60s松键、5.40s关延音。此段在引擎级驱动，不能证明现有无二极管矩阵能同时识别这组和弦 |
| 6.40s | C5，主音量一半，6.65s松键 |
| 7.20s | C5，主音量降到0，7.60s恢复，7.85s松键 |
| 后续至16s | 保留自然尾音并确认最终数字静音，无后期剪切尾音 |

拨弦在后三段可能叠加之前的尾音，这是自然衰减的预期结果；原默认/FM的延音只改变其释放时机。FM自身包络会自然衰减，打开延音不等于无限恒定响度。

音频头采样率为48077Hz，实际RTL为50000000/1040≈48076.923Hz，整数WAV头误差约1.6ppm。全部声音为RTL逐样本运算结果，试听文件不会送回FPGA作为录音播放。
