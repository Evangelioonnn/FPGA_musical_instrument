1. **原音色保留。** 新system的16秒默认演示与旧baseline全部769232个样本精确相等；不要因为换了工程误以为换了音色。
2. **输入逻辑已可复用。** 矩阵、EC11、数字压力→事件/配置→声音已在仿真接通；持键改映射、同音归属、鬼键/队列满释放已覆盖。真实电气针位和ADC驱动还缺，现有system.fs仍是自动演示。
3. **为C准备了真实数据。** 真实电平、带序号的状态快照、波形抽取、配置来源ACK和独立CDC候选可读[接口](../interfaces/SYSTEM_V0.md)。蓝牙/屏幕本身未实现。
4. **容量和效果有证据。** 8/16声部50MHz通过，32声部资源能放下但时序未过；短反馈延迟已独立RTL/数值/PnR验证，未并入默认系统。

使用[lab诊断工程](../../project/lab/README.md)：C4长音、A4长音、数字静音三份均已构建。打开对应gprj并确认Top后重新构建/核对.fs哈希，按原步骤SRAM下载即可。未改变Flash，也未新增外部连接。先测BCK/WS，再DIN，最后可触及的DAC单端模拟点与耳机输出；每次保存实际波形和固件SHA。

**耳机随音高变化的尖锐声仍未解决。** 本轮只证明数字逻辑与工具实现的边界，不能代替示波器/模拟链路验收。
