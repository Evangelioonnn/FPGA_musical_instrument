## 已知边界

本轮不实现C的最终UI、FFT、UART无线帧或LED曲谱，不冻结B控制板电气。
50MHz音频、真实SPI ADC与C的完整显示/蓝牙合并后仍需重新PnR和实物测试。
多位状态不能逐位同步；接口共同复位不等于支持任一时钟域单独复位。
本轮用户已对V2表示“听起来没什么毛病”，仅记录其实际反馈，不推定所有压力工况、模拟端延迟/噪声或整机已经通过。
