# V2验收后的整合顺序

本轮先交付现有硬件可用的五音色/32声部候选，用户试听通过后再冻结集成基线。
此页是后续顺序，不表示以下外设已经实现。

1. A按V2 BOARD_TEST确认五音色、32/12容量、两种延音、旧尾音、Lead、四谐波与止音，记录.fs哈希。默认电平与V1不同，须先对齐主音量。
2. A/B完成控制板输入契约：总25键/双区、逐键二极管或等价独立检测、5推子、实体ADC型号/模式/量程/供电、踏板及旋钮实际引脚。现有4×4和EC11继续作为回归，勿把当前验证接线当最终PCB。
3. ADC只增加采集/标定/整帧提交适配，复用已有adc_valid/ready和5路参数服务；避免再复制主音量或谐波状态。旧尾音的实例松键身份保持，移区只影响新击键。
4. C继续独立实现显示/蓝牙，用V2能力表、真实PCM和完整快照建立适配；预算不变。视频/FFT/通信拥塞不反压音频，跨域按完整记录握手/FIFO处理。
5. A建立音频+最小显示+最小通信的整机顶层，先解决Y12与Bank5，再接真实ADC和控制PCB，最后逐步开启频谱/曲目等。每次重新PnR并测deadline、clip及延迟，不把独立报告相加当实测。

资源先按A+输入29k/17k/70/78与C13k/10k/26/16/1PLL分账。
V2完整接口+当前输入仅综合余718 Logic，物理PnR余4块BSRAM。
SPI和新扫描器需要重新测；可优化RAM打包、共享更多拨弦算术、状态快照传送，
必要时回退较小拨弦池。以上是待验证方向，不能凭理论减少量宣称已经腾出资源。

暂不为扩容增加新音色、强制拨弦延音或改变Lead为单声部legato。
保留已认可V1及本轮V2对应指纹，按功能和资源实测选择下一步。
