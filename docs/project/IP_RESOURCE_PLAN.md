# IP 与资源优化：矩阵演奏版之后的路线

2026-09-22，基于本机Gowin V1.9.12.03官方IP目录和本轮实际构建；没有声称重新在线核对全部官网版本。官方入口：https://www.gowinsemi.com.cn/ip/index 。

## 当前测量与实际优化

八声部三音色矩阵顶层：23659/59904 Logic（约39.5%）、9684/60780 Register（15.9%）、40/118 BSRAM（33.9%）、97/118 DSP（82.2%）、19 IO；50MHz setup/hold无违例，最差余量0.251/0.048ns。以本轮最终构建证据为准，这个余量不是加入显示后仍会通过的保证。

本轮没有为了使用IP而替换已认可的声音。已经做了两项可说明的硬件优化：

1. 将矩阵键优先编码/身份查表与声部分配之间加寄存器，把串联长路径拆开。每次事件增加少量系统时钟，不改变音符次序或反压契约。
2. FM末级原64bit绝对值/加法/取反舍入改为等价商余数舍入，将舍入和限幅分开寄存。音频样本逐样本不变，计算延迟增加一个系统时钟，仍在64时钟混音等待窗内完成。没有靠false_path或降低时钟宣称收敛。

前两次失败结果保留在evidence，不能把“能生成.fs”当作时序通过。每实例仍保留三种算法，DSP是当前较紧的资源；本轮八声部不代表最终最佳架构。

## 官方模块按用途采用

| 模块/工具 | 用途 | 采用条件 |
|---|---|---|
| RAM_SP/RAM_SDPB/RAM_DPB/RAM_pROM | 正弦、拨弦延迟线、字模与图像 | 先看综合是否已推断BSRAM；显式IP需核对同步读延迟、读写冲突模式、初始化文件和数据位宽 |
| DSP_MULT/DSP_MULTALU等 | 音色、增益、滤波乘加 | 推断已经会用DSP；显式配置仅在映射/流水效果更好时采用，不能认为封装后自动共享 |
| DDS / DDS II | 多通道正弦与动态相位/频率 | 独立A/B实验；保持频率、精度和默认声音。DDS II v1.1目录明确列GW5AT-60B，说明支持最多16通道时分复用；不等于16个完整乐器声部 |
| FIFO/FIFO_SC | 跨域音频队列/同域事件队列 | 小型同域队列可继续纯RTL；实际跨域采样流优先考虑可靠异步FIFO。状态快照可继续握手，不强行全部改FIFO |
| 器件适配PLL + DVI_TX | C的像素时钟/TMDS输出 | C先核对60K/NEO的真实引脚，实际IP配置与时钟约束由A集成；不直接套138K整份CST |
| FFT | C的真实频谱 | 从完整采样流或正确抗混叠降采样流取数据；旧48倍抽点不能直接当频谱输入。需分帧、窗函数、资源和跨域预算 |
| GAO、虚拟IO工具 | 实物事件/PCM/串行链路内部捕获 | 独立调试构建；核实本板BL616/JTAG链路兼容性、触发和存储深度，再检查资源/时序；不能代替模拟示波器 |

软件目录存在不等于该配置已经在本板验证。每次真正采用记录：IP名称/版本、器件支持、许可、参数、生成脚本与必要HDL、初始化数据、仿真模型、时序例外来源。当前Altera版ModelSim不能被默认视作支持Gowin原语；要实际验证simlib。

普通模块也是可复用硬件。一个模块复制八次通常得到八份电路；跨声部共享需要独立状态和明确调度。每音频采样有1040个50MHz时钟，可评估共享FM算术、拨弦初始化调度、波表读端口；必须证明所有声部最坏情况都在截止前完成。不能只看平均吞吐，也不能把通道数直接当官方独立可闻振荡器数量。

## 接下来怎样比较

固定输入事件、参考电平、采样率，测每项候选的Logic/Register/DSP/BSRAM、setup/hold、每采样计算周期、初始化阻塞、数值误差和声部上限。优先释放DSP给更多有用声部或C的频谱，不能以填满资源作为目标。C先给显示模式/FFT点数预算，合入后重新做整机PnR。

2026-09-25 新增独立 [resource_optimization_lab](../../project/resource_optimization_lab/README.md)：正弦-only 下限从 97 DSP 降到 9 DSP；完整八声部共享正弦候选用 1 个同步 ROM 和 1 条波形×包络路径，最新构建为 3894 Logic、2277 Register、1 BSRAM、2 DSP、19 IO，50 MHz setup/hold 最差 slack 6.547/0.247 ns。与正弦-only 生产参考在同一事件边界逐样本比较 624 帧、0 mismatch。该候选只接受默认 timbre 0，尚未板测；FM/拨弦共享算子仍需独立验证。算子级共享乘法探针逐样本等价，DSP 从 32 降到 4。结果不能直接扩大为三音色整机结论。

暂不引入：软核CPU替代音频/显示、为简单键扫描引入总线处理器、无需要的DDR帧缓存、用标准Philips I2S发送器替换本板PT8211右对齐格式。Soft IP不等于软核CPU，功能和架构需逐项判断。

## 音质与产品优先级

统一演奏版通过后，主线是板测与杂音定位、主工程整合；资源优化可同时推进，但每次音频实现变化保留相同参考音。
真实杂音继续分数字实际输出、DAC输入/模拟输出、后级三段测量。保持已知干净电脑WAV作对照；真实GPIO与模拟电路尚未测量时，不把问题归咎硬件或宣称软件已排除。
回声、选择性延音暂缓；拨弦不强行延音。后续效果器依据可演奏性选择，完整ADSR/实时变调/端到端延迟和最终交互维度仍按赛题分别验收。
