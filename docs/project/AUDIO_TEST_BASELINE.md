## 基准身份

- 原始声音：`project/instrument/src/synth_voice.v` 的数学正弦 DDS，配合原 `adsr_envelope.v`。不替换成 expression 的第二/第三谐波配方，也不把末段八音和弦的音色2当作原音色。
- 听感参考：`project/instrument/sim/demo_simulated.wav`；音符 C4/E4/G4/C5，即编号60/64/67/72。
- 基准工程及音频保留；“类似钢琴”是用户对听感的称呼，不等于已完成原声钢琴建模。

## 固定参数

| 项目 | 默认值 |
|---|---|
| 采样率 | 50 MHz / 1040，约48076.923 Hz |
| 波形 | 现有1024点数学正弦ROM；第二/第三谐波权重均为0 |
| ADSR | attack_step=68、decay_step=6、sustain_level=32768、release_step=3 |
| 基准按住时间 | 31250采样，0.650秒；需要延长观察的测试另标注 |
| expression 中对应选择 | timbre=0、velocity=256、master_volume=65536 |
| 未测试时的附加效果 | glide_delta=0、bend_ratio=65536、sustain=0、sostenuto=0；无混响/延迟 |

保持原起音、衰减、保持和释放的规则；不能在测试延音时同时改成另一套包络或另一种波形。表达核心的默认值相同不保证混音后的音量和原单声部相同，必须另外核对电平。

## 每次只改变待测因素

- 测延音：固定音色、包络、力度、音高和增益，仅改变持键/踏板事件；普通延音与选择性延音用清楚可辨的音符时长，分别留出尾音和静音间隔。
- 测音量或力度：只改变目标音量或力度，其他参数固定。调制深度随力度变化等新音色表达留给独立音色实验。
- 测复音：各声部使用同一基准音色与包络，逐音增加/减少，以便核对独立发声。
- 测变调、滑音或弯音：保留基准音色/包络，仅开启该次所测的音高控制，并说明起止音和时间。
- 做新旧实现对照：同一音符序列、相同音符时长/包络、相同目标数字幅度和输出链路；算法实现本身作为被比较因素。
- 新音色比较单独标为音色试听，不混入故障排查或普通功能验收。先重放基准声音，再用相同短旋律比较候选。

## 音量也要控制变量

原单声部包络峰值约512码、保持段约256码。现有 expression 八声部固定除以8，单纯正弦保持段约32码；仅选择timbre=0不足以称为与原基准相同的对照条件。

每一对照组使用同一目标输出电平并记录：若为复音余量需要衰减，应在整组一致实施，不让被比较工程各自使用不同增益。需要电平扫描时单列测试阶段并明确幅度；不在本次规则记录中自动提升板卡输出。数字幅度不等于实际耳机声压。

电脑参考WAV使用明确记录的统一试听增益，不对每个音/每段独立归一化，否则会掩盖力度和音量差异。新旧板测尽量保持耳机、接线和供电条件一致。
