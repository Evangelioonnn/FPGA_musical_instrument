# 资源、IP 与产品化路线

本文档把 2026-09-17 宣讲会后的方向落到工程决策中。它是项目策略，不把尚未验证的 IP、引脚或 ADC 通道写成板卡事实。

## 1. 作品定位

作品的核心应是一个在 FPGA 内部逐采样、逐声部运行的实时电子乐器引擎。外部键盘、旋钮和压力传感器只是控制输入；真正需要展示 FPGA 特性的部分是并行振荡器、包络、混音、波形/音色处理和确定性音频输出。

因此，演示时要同时回答三个问题：

1. 输入变化后，音频是否在规定延迟内稳定响应；
2. 多个声部是否真正独立运行并能同时混音；
3. FPGA 的片上资源是否被有目的地用于波表、乘加、缓存、时钟和调试，而不是把功能变成一个不可解释的黑盒。

## 2. 三层实现边界

### 2.1 自研 RTL：比赛核心

以下模块优先使用结构清楚、便于讲解和仿真的 RTL：

- 音符事件接口和四声部管理；
- 每声部独立相位累加器、频率控制字和波形选择；
- ADSR 包络；
- 扩展位宽的多声部混音与饱和限幅；
- 矩阵键盘扫描/去抖、EC11 正交解码和输入事件适配；
- 统一的“每个音频采样输出左右样本”接口。

这些模块必须能在没有真实输入硬件时由测试平台产生事件，便于先完成 RTL 验证，再接入板卡。

### 2.2 Gowin IP 或原语：有明确收益时使用

IP/原语不是为了替代核心算法，而是用于把设计稳定地映射到 GW5AT 的专用资源。每次调用都要保留配置文件、生成日志、资源报告和一个不用该 IP 的参考版本。

| 资源或工具 | 计划用途 | 采用条件 | 验证证据 |
|---|---|---|---|
| BSRAM ROM | 正弦/三角等波表和音色表 | 波表深度或位宽使 LUT 实现明显增加，或需要稳定双口读取 | LUT/BSRAM 对比、波形误差、时序 |
| DSP | 包络乘法、增益、滤波或效果器乘加 | DSP 版本在资源、Fmax 或声部数上有可测收益 | DSP 数量、关键路径、音频样本对比 |
| PLL | 更精确的音频采样时钟或多个时钟域 | 分频方案无法同时满足采样率、抖动或时序要求 | 输出频率、锁定、STA、板上试听 |
| FIFO | 真实存在的跨时钟域或突发缓存 | 只有在接口时钟域确实分离时使用 | CDC 结构、延迟、满空边界仿真 |
| ADC 原语/IP | FSR 等模拟输入采样 | 先完成 GW5AT ADC 适配和 NEO Dock 通道/电气核对 | ADC 通道、采样值、校准曲线 |
| GAO 在线逻辑分析仪 | 调试音频帧、按键事件和声部状态 | 只在需要板上观测内部波形时加入 | 触发条件、采样时钟、额外资源 |
| VIO | 临时改变测试参数或触发测试音符 | 仅作为调试手段，不作为最终演奏输入 | 调试记录和移除后的资源对比 |

第一版不主动引入 DDR3、软 CPU 或复杂效果 IP。它们可能有价值，但会增加配置、验证和讲解成本，且不直接提高基础电子乐器指标。

### 2.3 已验证的板卡接口层

`project/audio_probe` 的 PT8211 输出层保持为唯一音频硬件出口。合成核心只产生左右 16 位样本，不复制 PT8211 状态机，也不把其 LSBJ 格式误称为标准 Philips I2S。`project/test` 保留为 PMOD LED 基线。

## 3. 资源利用率的记录方式

每个里程碑都保存 Gowin 的综合和 PnR 报告，至少记录：

- LUT4/逻辑单元、FF；
- BSRAM 数量和位容量；
- DSP 数量；
- PLL、全局时钟和 I/O Bank 使用情况；
- 最差 setup/hold slack、Fmax 和违例端点；
- GAO/VIO 额外资源；
- 功耗估计（只作为工具估计，和实测供电现象分开）；
- 输入到音频采样的逻辑延迟、最大稳定复音数和采样率。

资源利用率不追求无意义地做高。每一项占用都要能解释为声部数、波表精度、音色数量、效果器、调试可观测性或产品接口带来的收益。报告中同时保留“参考实现”和“优化实现”，这样可以展示优化前后的 LUT/BSRAM/DSP/Fmax 变化。

当前两个基线供后续比较：LED 工程用于板卡和时钟约束基线，`audio_probe` 为 59 个逻辑单元、46 个寄存器的音频输出基线；这两个数不代表正式合成器的资源预算。

2026-09-18新增M2数字基线：`project/polyphony` 自动四音演示为2007 Logic（1801 LUT+206 ALU）、438寄存器、4个BSRAM pROM、4个DSP MULTALU27X18。四套波表读取及包络乘法映射到专用资源；50MHz下setup +9.370ns、hold +0.188ns，TNS为0。功能/构建验证通过、尚未板测；自动序列可能优化未用音符逻辑，不能当作完整输入乐器最终占用。未来并行扩展与时分复用以该报告作对照，详见 `project/polyphony/VALIDATION.md`。

## 4. 产品化分阶段

2026-09-18表达候选资源：`project/expression` 八声部/三谐波配方/表情控制数字验证通过，最终7271 Logic、1516寄存器、24 BSRAM、49 DSP等效单元；50MHz最差setup +3.715ns、hold +0.051ns，TNS均0。初版串行优先选择的setup为-0.265ns，优化为并行选择后消除违例；等价音色公式减少乘法，DSP从58.5降至49且1153848个样本完全相同。报告和参考版本在该工程reports目录。资源对应自动演示、meter无消费者被移除，不是带全部输入/显示/效果器的最终预算；板测待做。

产品化不能阻塞 11 月前的比赛版本，采用三阶段接口兼容路线：

1. **开发板阶段**：Tang Mega NEO Dock + 4×4 矩阵键盘 + EC11 + FSR，先用杜邦线完成独立验收。顶层只依赖行列、编码器事件和归一化力度等逻辑接口。
2. **自制 PCB 阶段**：先根据演奏任务选定琴键/网格布局和键数，再把按键、编码器、所需表情传感器、保护电阻、连接器和电源/地线布置到载板；4×4只作阶段1验证，不限制成品。输入模块保持音符/表情事件契约，扫描行列和物理引脚允许随设计改变。PCB投板前必须冻结实际FPGA引脚表和输入电压，并安排小样与改版时间。
3. **外壳阶段**：根据 PCB 和耳机/扬声器接口位置设计 3D 打印外壳；把 LED、旋钮和键盘标识纳入面板设计。外壳属于展示增强项，核心功能完成后再做。

阶段 1 的 RTL 和阶段 2 的 PCB 之间通过接口契约隔离，今后可以替换输入板而不改动 DDS、ADSR、声部和混音模块。

## 5. 三人协作建议

- **用户：核心与集成线**：DDS、波表、ADSR、声部、混音、音色/效果器，统一Gowin顶层/CST/SDC与最终资源/时序、音质验收。
- **队友B：交互模块线**：演奏布局、选音与表情硬件、小样/校准/线序、后续PCB/结构；与用户共同约定FPGA输入适配边界。
- **队友C：通信与反馈线**：蓝牙参数/状态链路、客户端最小功能、FPGA状态反馈与所选显示驱动，独立仿真/资源验证。

这是2026-09-18用户提案对应的推荐草案，完整交付与接口约定见 `TEAM_WORKFLOW.md`。外部接口预算先确定需求再核对实际引脚，内部DSP/BSRAM等随功能迭代。每条线交付验证记录；蓝牙和显示运行不阻塞本地音频。三条线都要能复现依赖工程；合并前以报告和波形审查，不能只以“能综合”作为交付标准。

## 6. 11 月前里程碑

- **M0（已完成）**：PT8211 耳机链路和 PMOD LED 输出实测。
- **M1（数字验证通过、音质待解决）**：固定音符 DDS + ADSR 已接入音频输出，资源基线已记录。
- **M2（数字验证通过、板测待做）**：四声部独立相位、抢占策略、混音限幅；综合/PnR/内部时序通过并保存报告。
- **M3**：矩阵键盘单键和四键实测；限制无二极管矩阵的鬼键范围。
- **M4**：EC11 控制音色/八度/效果参数；FSR 通过 ADC 形成力度控制；形成至少三个独立演奏维度。
- **M5**：至少两种音色、LED/波形或频谱反馈、资源优化对比和演示脚本。
- **M6（冻结）**：完成稳定版本、接线图、引脚表、时序/资源/延迟/功耗记录；自制 PCB 和外壳只在不影响冻结版本时推进。

每个里程碑都必须同时满足规格、RTL 仿真、综合、布局布线和相应的板上验收条件；尚未实测的内容继续标记为待验证。

## 7. 近期决策

在矩阵键盘、编码器和 FSR 到货前，M1/M2的参考RTL及数字验证已完成，继续准备输入验收并定位板卡音质。IP 评估从 IP Core Generator 中选择 `GW5AT-60B` 后进行，先确认工具实际提供哪些可用模块，再决定是否生成 ROM/DSP/PLL 配置文件。

官方 EDA 手册中关于层次化设计、避免门控时钟/锁存器、使用专用时钟使能、RAM/DSP IP、资源报告和时序收敛的要求，作为本项目的工程约束；不把手册中的通用示例直接当成 NEO Dock 的引脚或接口说明。

## 8. 资料优先级

遇到结论冲突时按下面的顺序处理：

1. NEO Dock 官方原理图、官方全引脚约束和实际板上测量，用于接口、引脚、电压、方向和音频连接；
2. Tang Mega 60K 官方 Wiki 和器件选型资料，用于完整器件型号、封装、Device Version 和板卡资源概览；
3. Gowin 针对 GW5AT/Arora V 的器件、原语、综合、时序和 IP 手册，用于工具与 FPGA 架构行为；
4. 竞赛官方题目，用于硬性指标和评分方向；
5. 学长整理、论文、网络例程，用于思路和工作方法，不能覆盖前四级资料。

当前 ADC 手册中有针对 GW5A-138/GW5AT-138 的章节；不能因为文档里出现 Arora V ADC 就直接假定 GW5AT-60 和 NEO Dock 的 ADC 通道、量程或引脚完全相同。FSR 接入前，必须在 IP Core Generator 的 `GW5AT-60B` 过滤结果、器件手册和 NEO Dock 原理图之间完成交叉核对。
