- `project/test` 是 PMOD LED 基线，不作为正式合成器顶层直接修改。

## 顶层数据流

```text
矩阵键盘/仿真事件 ─┐
编码器/仿真参数 ────┼→ 输入适配层 → 音符事件/参数事件
FSR ADC/仿真力度 ──┘                    ↓
                              按键状态与声部管理
                                      ↓
                              DDS + 波形选择
                                      ↓
                              ADSR 包络
                                      ↓
                            4 声部混音与饱和
                                      ↓
                         每采样左右样本（16 bit）
                                      ↓
                             PT8211 输出层
                                      ↓
                                耳机输出
```

音频输出层、合成核心、真实输入层分别验证。矩阵键盘的行列扫描、编码器边沿检测、ADC 读取不得直接写入 DDS 或 PT8211 状态机。

2026-09-18输入边界修订：用户明确4×4只用于验证，成品键数与形态未定。**物理键盘布局、电气扫描行列、可用音域和复音数是四个独立设计量**；25键琴键也可以用电气矩阵扫描。后续输入层分为“扫描/传感→稳定物理键状态→键位映射→音符事件→声部管理”，避免将行列号直接写进合成器。扫描行列拟参数化，键位映射独立；当前RTL尚未实现，不宣称已支持任意尺寸。

已实现M2接收7位音符号，不依赖4×4，仍只有四个同时发声的声部。若最终网格含重复音，或加入多输入源，需在输入层维护各物理键按下时的音符映射及同音持键计数，聚合后再送核心；松开一个同音键不能提前关闭另一个。同样，持键时改变八度/音阶映射，松键必须针对原先按下的音符，防止挂音。这些输入源管理规则仍待实现。夜间新增expression候选已扩展音符力度、retune、全局弯音及配置接口，详见其INTERFACES；逐键压力及物理采集尚未实现，原M2接口未改。

最新交互定位：琴键、网格和其他自研演奏面平等考虑。未来如评估选音与拨奏分离，输入适配层须区分“选中音符”和“触发发声”，不能把每次选中都直接当note_on。连续表情应有明确的声部作用范围、参数边界和平滑处理，弯音以音高偏移控制保持原音符身份；音色切换尽量保持键位音高映射稳定。夜间expression候选已实现部分表情RTL并数字验证；新传感器、选音与拨奏分离、实际手感及板测仍待完成。

## 模块顺序

### 1. 音符表和 DDS

- 输入：`note_on`、`note_off`、音符编号、力度；音频采样时钟使能；复位。
- 输出：有符号音频样本、当前频率或相位用于测试。
- 每个振荡器有独立相位累加器和频率控制字；不使用延时循环，也不播放预录音。
- M1/M2已采用正弦查表；方波保留为audio_probe基线，其他波形尚未实现。波形选择属于音色参数，不改变声部管理。
- 仿真要求：给定采样率和音符编号，测量连续周期；相邻音符频率比接近 2^(1/12)；相位溢出连续。

### 2. ADSR

- 阶段：`IDLE → ATTACK → DECAY → SUSTAIN → RELEASE → IDLE`。
- `note_on` 从任意非 `IDLE` 阶段重触发时，第一版回到 `ATTACK`，不产生未知状态；`note_off` 进入 `RELEASE`。
- 包络使用每采样更新的定点增减，范围 0 到满量程；不在 50 MHz 每个时钟无条件改变音量。
- 仿真要求：阶段顺序、峰值不超过满量程、释放最终归零、快速重触发不锁死。

### 3. 四声部管理

- 初始目标：4 个独立声部，满足题目基础复音要求。
- 每个声部保存：占用标志、音符编号、相位、包络阶段/值、触发序号。
- 新 `note_on` 优先分配空闲声部；无空闲时采用最早触发或已进入 RELEASE 的声部，策略固定并在说明中写明。
- 同一音符重复按下时，第一版允许重新触发该音符对应声部，避免无限占用。
- 仿真要求：单音、四音同时按下、第五音的抢占策略、独立频率和独立包络。

### 4. 混音和限幅

- 声部样本先扩展位宽再相加，不能直接截断 16 位。
- 混音输出采用可证明的饱和限幅，避免溢出回绕造成爆音；保留内部峰值用于测试。
- 仿真要求：全零、单声部、正向溢出、负向溢出、正负抵消，以及四声部峰值。

### 5. 真实输入适配

- **4×4 矩阵键盘**：8 根行列信号，扫描与去抖后输出 `note_on/note_off`。普通无二极管矩阵第一阶段限制为可靠的单键/少量组合，并记录鬼键限制。
- **EC11 编码器**：A/B 两路正交解码，按压开关另算一路；去抖后输出步进事件，用于音色、八度或参数选择。不要把机械抖动直接送给合成器。
- **FSR 压力传感器**：先用 3.3 V 分压接底板 ADC，校准空载和按压范围；输出归一化力度值。ADC 引脚、输入范围和采样时序核对完成前不写最终 CST。
- 所有真实输入都保留仿真输入端口/测试任务，使核心模块不依赖实物。

## 到货前的验证安排

1. 固定音符 DDS：仿真音符序列，检查频率和相位连续性。
2. ADSR：仿真按键事件，检查阶段和边界。
3. 4 声部管理：仿真四键和抢占，第五声部验证确定性。
4. 混音限幅：独立定点测试，检查不溢出回绕。
5. 合成核心接入已经通过的音频输出接口，仿真 PT8211 checker；之后才综合和上板。

真实矩阵键盘到货后，先只接 8 根无源行列线，完成扫描/去抖单独验收，再接入合成核心。编码器和 FSR 分别验收，避免一次接入三个未经确认的接口导致定位困难。
