# 参数接口与当前能力表

> 历史契约，仅用于本页对应旧工程。当前C对接先读[AUDIO_CORE_V2](AUDIO_CORE_V2.md)、[传输契约](AUDIO_TRANSPORT_V1.md)和[接口索引](README.md)；下文“当前/新”均指当时版本。

历史集成候选[system v0](SYSTEM_V0.md)只接受0/4/5/6，其他地址明确拒绝，并提供独立pressure_gain和配置应答来源。下面的expression/固定试听表仍描述历史工程，不能把旧“接受但忽略”当作新接口行为。

同步50MHz，`cfg_valid && cfg_ready`接受4位地址、32位数据。控制器应答包含`cfg_ack/cfg_accepted/cfg_applied`；非法值拒绝并返回0xffffffff。读状态、事务序号、蓝牙帧格式尚未实现。多参数预置不是原子提交；需先等配置应答，再发依赖它的音符。

| addr | 意义/单位与合法范围 | expression候选 | 固定试听baseline |
|---|---|---|---|
| 0 | 音量Q16幅度0..65536 | 生效，增益每采样向目标走128 | 生效 |
| 1 | 音色0..2（现有数学配方） | 生效，有权重渐变 | 接口接受但声音忽略；始终原voice |
| 2 | 弯音频率比Q16，32768..131072 | 生效，约±12半音 | 接口接受但声音忽略 |
| 3 | glide_delta，0..0x7fffffff，相位步长码/采样 | 生效，0直接更新 | 接口接受但声音忽略 |
| 4 | sustain，0/1 | 普通延音 | 生效 |
| 5 | sostenuto，0/1 | 上升沿锁住此前held集合 | 生效 |
| 6 | 全释放，仅写1合法 | 走release；不是立刻静音 | 生效 |
| 7/8/10 | A/D/R每采样步长，1..65535 | note_on快照 | 接口接受但声音忽略；固定68/6/3 |
| 9 | S保持级，0..65535 | note_on快照 | 接口接受但声音忽略；固定32768 |

这个差异来自baseline为保持音色直接实例化原instrument voice；`accepted`只能说明控制模块接受了值，不能证明下游使用。**C的第一版UI/协议只能公开实际支持能力，或在适配层拒绝不支持配置。** 完整能力查询/读回协议要与A设计，不能简单转发ACK当整个产品成功。

音量从0到满幅需512采样，约10.65ms，这是平滑斜坡长度，不是音符响应或整个系统延迟。velocity是note_on幅度，FSR若作持续表达需映射独立连续控制；现有接口未提供逐键压力更新。

普通延音使松键音继续保持，抬踏板后释放；选择性延音只捕获踏板踩下瞬间此前的held集合（踏板由0到1）。两者同时使用以实际管理器测试为准。软音踏板尚无独立状态机，可作为后续增益/音色映射提案；不要标成钢琴三踏板已全实现。
