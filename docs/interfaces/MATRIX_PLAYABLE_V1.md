# 矩阵演奏实例接口候选

> 历史契约，仅用于本页对应旧工程。当前C对接先读[AUDIO_CORE_V2](AUDIO_CORE_V2.md)、[传输契约](AUDIO_TRANSPORT_V1.md)和[接口索引](README.md)；下文“当前/新”均指当时版本。

2026-09-21/22，A，分支`codex/matrix-playable-v1`，起点`f9bcd79`。对应[实现规格](../../project/input/matrix_playable/SPEC.md)。这是独立实例事件候选，**不修改SYSTEM_V0原有事件字、配置地址或快照布局**。

## 事件边界

50MHz，同步高有效rst。`event_valid && event_ready`在上升沿接受；反压时valid与载荷保持，panic/输入故障可撤销待处理事务并清全局归属。

| 字段 | 位宽 | 语义 |
|---|---|---|
| event_off | 1 | 0=新实例，1=松开特定实例 |
| event_token | 32 | 非零生命周期身份；同音重复按下使用新身份 |
| event_note | 7 | on时接受48..84；当前实体映射60..75；off不靠音号匹配 |
| event_timbre | 2 | 0原默认、1拨弦、2FM；on时锁定，off不改变音色 |

输入适配器按快照次序发事件，一份快照先发off再发on。按下时保存身份，松开引用原身份。token单调增加，禁止回绕重用；耗尽时进入故障等待重新配置。未来蓝牙输入必须共用身份分配器或定义可证明不冲突的来源命名空间，不能各自从1开始后直接合并。

声部满时事件传输仍正常握手，但on被拒绝，`rejected`脉冲和`rejected_count`记录。`accepted`只表示on被分配；off有匹配则发给对应槽，无匹配计数但不误伤其他音。自然结束的拨弦之后松键、或先前被拒的on对应off，都可能合法地无匹配。调用者不能把握手等同于一定发声。

## 参数与行为

主音量Q16，17bit，0..65536，逐采样向目标最多变化128。普通延音是布尔保持状态。原默认release_step为16bit整数包络减量；FM release_index为3bit查表配置。二者在实际开始释放时分别锁存。拨弦忽略普通松键/延音/尾音配置，按自然衰减回收。音高、音色、音符身份在声部内锁定。

panic和鬼键/溢出先清输入排队、停止接受新音，再平滑音量到0，帧完成后清所有声部。物理全松且去抖keys全零后重新武装。最终产品的恢复策略可在接口版本更新时调整，不能独立丢失off。

## 给B/C

B：本次矩阵接PMOD1/J8，旋钮仍PMOD0的T18/R17；按键使用底板1.5V用户键。J16用于暂时的板载RGB反馈。这些是验证版资源占用，最终IO仍须统一表决与A集成。控制板的逐键隔离可解除现有矩阵的鬼键限制。

C：仍可按SYSTEM_V0开发通信/显示模块。新实例身份、音色与按压状态尚未接入该快照，不能把现有界面显示成已经观察到这版三音色。A之后需提供版本化快照或适配器，并统一本地/蓝牙参数所有权。本轮所有状态在单一50MHz域，接显示域仍需CDC。
