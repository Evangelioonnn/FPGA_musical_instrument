# system v0共享接口候选

本页对应`feat/playable-system-v0`；不是对旧expression/baseline端口能力的追溯修改。A/B/C集成以此为候选契约，改动在PR标出消费者影响。

## 时序与数值

音频域50MHz、同步高有效rst。采样率为50MHz/1040≈48076.923Hz；WAV头取整数48077。所有valid/ready仅在同时为1的时钟沿接受；生产者被阻塞时保持valid和完整载荷。音符接口沿用[EVENTS](EVENTS.md)。

音符FIFO深度16；N≥32时多一个输出寄存级，8/16的默认时间关系保持原样。panic清FIFO/输出级并对声部走release，**不是瞬间归零**。音符kind=0且velocity=0按off处理；kind=3由管理器忽略。无事件事务ACK，不能用cfg_ack应答音符。

固定音色：原正弦DDS+ADSR 68/6/32768/3。velocity 9bit、有效0..256；pressure_gain和master_volume为17bit无符号Q16幅度0..65536。pressure禁用必须传65536。压力先钳位，与master相乘，取product[32:16]作为下一目标；gain每sample_ce向目标移动最多128。配置ACK表示寄存器接受，不表示平滑增益已走到目标。输出样本为16bit有符号。

## 配置与来源

| 地址 | 合法值 | 行为 |
|---|---|---|
| 0 | 0..65536 | 主音量目标 |
| 4 | 0/1 | 普通延音 |
| 5 | 0/1 | 选择性延音，0→1捕获此前held |
| 6 | 仅1 | 清两类踏板状态、释放声部和队列 |
| 其他 | 无 | ack=1、accepted=0、applied=0xffffffff |

local/host两个配置来源公平仲裁，反压期间锁定来源和载荷。cfg_source_host在对应ACK周期标识应答来源。接受后的时钟周期ack/accepted/applied有效；多个连续事务可能连续周期ack=1。没有蓝牙事务编号、CRC、重试或断连协议。主机配置可以与音符流并行，但对“配置后再演奏”的操作，先等ACK再送音符。

本地EC11维护自己的绝对音量目标（上电满幅，每格4096），**主机同时改变音量后再转旋钮可能跳回旋钮的目标**。首版C应只在明确模式内调音量，或下一次集成新增共享目标回传/相对增量协议；不要默认已经解决多控制器参数所有权。外部emergency释放音符，但保留配置踏板状态；cfg地址6才清踏板。

## 输入快照、映射和恢复

每个键位映射7bit音号，槽0在最低位；按下时锁存映射。只换布局不会给持有键改音高，再次按下才使用新映射；显式retune事件用于持键变调。多个同音键共用一个音符身份，最后一个松开才off；当前不支持多个同音独立包络。

输入快照队列默认8份，满时又来状态变化则报故障、清未处理事件并释放。判定用寄存的占用量，即使同周期可能出队也采取保护；这是有意的保守策略。鬼键/满队列后等待物理全松；panic同样阻止旧按键自动再触发。正常valid等待ready不是故障。若系统堵塞来源不在输入快照队列，必须在该来源设计类似可测的错误处理。

## C可读取的状态

`snapshot_valid`约每1024个有效混音样本一次（46.95Hz）；payload总宽 `85+18*N`。`snapshot_data`在valid到来时是一致抓取的声部/控制状态；peak/clip对应刚完成的电平窗口，窗口之后的声部状态不能当窗口内历史。

从最高位到最低位依次为：

| 字段 | 位宽 |
|---|---|
| sequence | 32，从0递增，允许回绕 |
| master_volume、gain | 各17 |
| meter_peak | 16，无符号绝对值，−32768对应32768 |
| meter_clip、sustain、sostenuto | 各1 |
| occupied、held、gated、sost_latched | 各N |
| notes、pitches | 各7*N，槽0最低 |

N=8时229位。例如pitches=[55:0]、notes=[111:56]、四组mask依次[119:112]/[127:120]/[135:128]/[143:136]（从低往高为sost/gated/held/occupied），踏板/clip=[146:144]，peak=[162:147]，gain=[179:163]，master=[196:180]，sequence=[228:197]。

`wave_valid/wave_sample/wave_index`每48个混音样本抽取一个，约1001.60点/s；wave_index是原采样计数，从0开始、32bit回绕。**未做抗混叠滤波，不能把这条抽样流直接用于频谱/高频音准测量**。做FFT应从sample_valid取得全速样本或另加正确降采样滤波/分帧RAM。左右目前相同，L/R李萨如仍只有直线。

## 跨显示域

`snapshot_cdc`采用保持总线＋请求/应答toggle，控制信号两级同步。src_valid && src_ready接受；忙时的新快照丢弃并累加dropped，不阻塞音频。dst_valid是目标域单周期脉冲；显示在帧边界采纳最近快照。

两个复位必须属于同一次共同链路复位，独立复位会破坏toggle约定，当前不支持。仿真证明的是payload无撕裂/不重排；C集成时仍须按真实像素时钟核对同步级属性、复位释放与总线最大传播约束，不能简单把所有跨域路径无条件false_path。该模块没有包含PLL、图像RAM、像素时序或引脚约束，也不是全速音频异步FIFO。
