# 外屏资料核对与C的起步范围

C负责板卡外接显示器的FPGA可视化。当前还没有点亮外屏，也没有冻结显示分辨率、输出原语或针位。这个目录不暗示已完成视频链路。

## 必须先解决的资料差异

- [NEO Dock 60K原理图](../../references/board/neo_dock_60k_schematic.pdf)第15/21页：2025-03-31 Rev1.4，标题DVI(Only FOR TX ON 60K)，J29。该页DVI差分线标注包含AA22/AA23、V24/W24、AB24/AC24、Y22/Y23。
- [下载的全引脚CST](../../references/board/full_pins_reference.cst)中TMDS数据对却为J14/H14、J15/H15、K17/J17，时钟对G15/G16。
- 两份标注不一致；尚未证明是版本、命名或参考工程来源差异。不能选一份“看起来更官方”便下载。先沿底板连接器→板间座→对应核心板图纸核对，并确认实物版本及适用官方例程。不要把上面球号列表直接转成CST。
- iBOM日期2024-09-23，早于该原理图，只作元件位置参考。T14在上述图纸上是CEC标注，不能当作未经核实的HPD输入。
- “官网资料”里的DK_START板不是Tang NEO；不用它做本板外设布线依据。

## 在引脚确认前可独立完成

先做可综合的像素/行/帧计数、有效区与同步测试，输出彩条或简单键盘/网格状态；用testbench导出PPM图片检查边界和配色。显示模式由C选择，640×480等低分辨率可作为起步候选，不在文档中当成既定配置。

绘图模块接收统一的note/held/gated等状态快照；输入先由TB模拟。音频状态不随便跨像素时钟域，快照双缓冲/握手需和A约定。见[显示接口](../interfaces/DISPLAY.md)。确认硬件后，再加入PLL、输出串行化/TMDS及对应约束；测试一帧正确不等于物理接口已达标。

## 照片/RGB/ROM方案的可行性

用户提出“MATLAB把琴键照片或五线谱转RGB再打包ROM”的方向**可评估，未选定**。RGB数组是素材；ROM IP提供存储和读延迟，还需要坐标寻址、图层/高亮、扫描时序、像素时钟及物理编码输出。

640×480×24位未压缩背景需7,372,800 bit，超过60K约2.6Mbit量级片内BSRAM，且声音/缓存还要占用。最终容量以准确器件报告为准。可比较程序画琴键/谱线、调色板索引、字模/图块、小分辨率背景，最后再评估外存，首版不用预设DDR必须接入。

实时波形需要采样/抽取缓存，电平表的最后一个样本不能替代完整波形。当前L/R相同，画L/R李萨如是直线；可以用两个明确定义的不同信号或延迟信号作展示，但必须标清含义，不伪称真实立体声轨迹。实时频谱需FFT/窗与定标，是单独资源任务；视频背景动画不算实际音频频谱。
