# 外屏资料核对与C的起步范围

C负责板卡外接显示器的FPGA可视化。**9月25/26日更新：独立彩条已在A的NEO实物与普通HDMI显示器上稳定显示1920×1080、显示器报告61Hz。** 见[探针源码](../../project/visual/dvi_colorbar_probe/README.md)和[板测记录](../../project/visual/dvi_colorbar_probe/BOARD_TEST.md)。这确认了本机视频输出链路；尚未完成音频/显示整合或实时可视化。C按[团队预算V1](../team/RESOURCE_BUDGET_V1.md)独立开发。

## 已验证链路与整合限制

| 信号 | P球号 | N球号 |
|---|---|---|
| TMDS data0 | J14 | H14 |
| TMDS data1 | J15 | H15 |
| TMDS data2 | K17 | J17 |
| TMDS clock | G15 | G16 |

探针为DVI/TMDS视频，通过HDMI外形接口和普通HDMI线显示；无HDMI音频、DDC/EDID自动选模式。主时钟V22为50MHz；1 PLL产生150MHz像素时钟与750MHz串行FCLK，DDR每通道1.5Gbit/s；总时序2200×1125，实际约60.606Hz。复现可沿用该模式，标准148.5MHz/1080p60兼容模式由C后续验证；显示器支持240Hz不要求FPGA输出240Hz。

- 探针Y12作低有效复位，但音频同键切音色，不能原样合并；整机显示采用统一内部复位策略。
- 音频J16状态LED约束3.3V、显示K17/J17差分约束2.5V，而报告都位于Bank5。需核对实际VCCIO和该器件差分IO规则后统一；显示成功不等于CST填写的Bank电压就是实物值。
- 独立彩条PnR为347 Logic、83 Register、0 BSRAM、0 DSP、1 PLL、10 IO；不是C全部显示/频谱预算。音频与彩条的独立资源数不能替代合并实现。

## C可独立继续的内容

在已验证扫描/输出上增加键盘或网格状态，用testbench导出PPM图片检查边界和配色。显示模式由C选择；可以先沿用已板测1080p，也可独立验证更低分辨率，无需重新从猜引脚开始。

绘图模块接收统一的note/held/gated等状态快照；输入先由TB模拟。音频状态跨像素域需一致性快照/握手。当前[显示消费者入口](../interfaces/DISPLAY.md)连接V2和接入包；界面目标见[C规划](../team/C_HANDOFF_AND_DISPLAY_PLAN.md)，资源边界见团队预算。复用PLL、输出串行化/TMDS及对应约束时仍需验证新顶层；测试一帧正确不等于整合物理时序已达标。

## 照片/RGB/ROM方案的可行性

用户提出“MATLAB把琴键照片或五线谱转RGB再打包ROM”的方向**可评估，未选定**。RGB数组是素材；ROM IP提供存储和读延迟，还需要坐标寻址、图层/高亮、扫描时序、像素时钟及物理编码输出。

640×480×24位未压缩背景需7,372,800 bit，超过60K约2.6Mbit量级片内BSRAM，且声音/缓存还要占用。最终容量以准确器件报告为准。可比较程序画琴键/谱线、调色板索引、字模/图块、小分辨率背景，最后再评估外存，首版不用预设DDR必须接入。

实时波形需要采样/抽取缓存，电平表的最后一个样本不能替代完整波形。V2干声L/R相同，画L/R李萨如是直线；短房间效果开启后可能产生真实声道差异。可以用两个明确定义的不同信号或延迟信号作展示，但必须标清含义，不伪称真实立体声轨迹。实时频谱需FFT/窗与定标，是单独资源任务；视频背景动画不算实际音频频谱。
