# J13 40针扩展口：控制板可用GPIO · 2026-09-26

用户指出上一版预算漏算40针排针，本轮已核对NEO底板原理图、核心板电源页及全引脚参考CST。**B可以使用J13，不受此前PMOD 12根分配限制。** 本页是资料核对结果，尚未新增J13实物逐针通断或GPIO板测。

角色A；分支`codex/resource-feature-budget`；阅读基线`9f15651`。范围仅文档/资源清单，不修改CST或固件。

## 连接与容量

- NEO底板第19页的 **J13 / SDRAM0 CONN. / TH_PIN_2x20_2.54mm**，图中注明靠近PCIe连接器。`SDRAM0`是连接网络的用途名称；未连接外部SDRAM模块时，这些FPGA管脚可以配置为普通数字GPIO。
- 40针中，**36根为直接信号，2根为经0Ω电阻选择的信号，另2根为5V与GND**。不能说40根都是GPIO。
- J13第29针经R68到DM0/F14，第30针经R70到DM1/F13；第19页将R69（转接3.3V）和R71（转接GND）标为不装。实际使用29/30前确认电阻装配/通断，避免把电源配置当GPIO。
- 信号来自Bank1/2。核心板30353第6页显示`VCCIO1_2`经FB15接3.3V；全引脚参考CST的SDRAM信号也用LVCMOS33。J13第11针的5V电源不表示GPIO能承受5V。
- **J13与现有PMOD、音频、已板测TMDS映射没有球号重叠**；下表38根球号已和相应CST比对。这里不把资料相符扩大为所有实物针位已验收。
- 第19页另一组 **J14 / SDRAM1 CONN.** 用不装符号标出，并与PMOD/DVP共享信号，不能作为另外38根完全独立GPIO加到总数里。连接器位号J14和FPGA球号J14是不同概念。

因此以J13直接信号+两组PMOD为本阶段候选池，可计 **36+16=52根独立信号**；J13第29/30针确认电阻后可到54根。这是候选可接出信号池，不包括其他仍需逐项核对的接口，也不是全部立刻分配给B。

## 对B/C预算的修正

B的新控制板优先评估J13，第一版为其预留最多32根直接信号，J13另留4根直接信号和2根条件信号用于扩展/调试。可设计直连行列扫描、编码器、SPI ADC、踏板和灯驱动；是否采用移位寄存器由键数、布线和延迟决定，不再为满足12根而强制串行化。

C蓝牙继续预留PMOD 2–4根；其余PMOD信号可作验证、控制扩展或其他模块，分配时扣除仍在使用的旧矩阵/编码器。上述是终版迁移方案，当前10根PMOD验证接线无需立即改变。实际超过32根的有用需求可在52根候选总池内重新分配，32根不是器件硬上限。

如果后续C用J13接外部SDRAM做大图像/录音缓存，将与B控制板冲突，需要重新分配。当前C按片内缓存和程序绘图预算，不默认占用J13。核心板上的DDR3与J13外接SDRAM接口不是同一组管脚，不能混为一谈。

这次增加的是可用连接资源，不增加FPGA的BSRAM/DSP容量。音频资源优化和C内部资源额度继续按[团队预算](../team/RESOURCE_BUDGET_V1.md)执行。
